# 사진에서 결과 수정, 검사 기록까지

이 안내는 작업 중심 화면 개선 소스의 사용법입니다. 현재 사용 중인 앱·웹의
버전과 반영 여부는 별도로 확인하세요. 기존 학습 전 데이터·전처리 작업대는
그대로 사용합니다.

## 1. 작업에 맞는 라벨 도구

간단히 보기에서는 지금 작업에 필요한 도구가 먼저 보입니다. 다른 도구는
**다른 영역 도구**에서 펼칠 수 있고, 모두 보기에서는 전체 도구가 나옵니다.
선택 중인 도구는 접힌 영역에 숨지 않습니다. 펼치거나 접는 것만으로 기존
도형이나 선택 도구가 바뀌지는 않습니다.

사진 분류의 정답은 **이 이미지의 클래스**에서 고릅니다. 사진 안의 영역은
선택 사항입니다. 영역이 없다는 안내가 사진의 분류 정답도 없다는 뜻은
아닙니다. 기존 저장·실행 취소·확대·점 편집과 단축키를 계속 사용할 수 있습니다.

## 2. 숫자에서 문제 사진으로

결과 확인에서 모델의 작업 종류와 시험 이미지 묶음을 선택합니다. 이름은
읽기 쉽게 표시하고, 실제 모델 작업 ID와 자료 버전은 기술 근거에 보존합니다.

미리보기의 **미검 이미지 보기**는 놓친 불량 사진을, **과검 이미지 보기**는
정상을 불량으로 본 사진을 해당 목록에 모읍니다. 사진을 선택해 원본과 결과를
비교하고, 필요한 경우 기존 **라벨 수정**으로 이동합니다. 숫자를 누르는
것만으로 평가나 라벨 저장을 새로 실행하지 않습니다.

**현재 미리보기 기준**과 **저장된 평가 기준**은 구분합니다. 미리보기 점수를
바꿔도 저장된 미검 기록이 바뀌지는 않습니다. 저장된 미검을 확인하는 기존
행동은 그대로 남습니다. 객체 단위·픽셀 단위 지표는 이미지 단위 미검·과검과
다르며, 지원하지 않는 모델에서 같은 의미로 계산하지 않습니다.

간단히 보기에서는 사진 비교 공간을 먼저 확보하고 고급 통계·기술 근거를
펼쳐 볼 수 있게 했습니다. 실행 오류·원격 작업 상태와 취소 제어는 접지 않습니다.
취소 요청을 보냈다는 표시와 작업자가 실제로 끝났다는 표시는 서로 다릅니다.

## 3. 다음 검사와 과거 검사 구분

검사 사용 화면의 **다음 검사에 사용할 활성 플로우**는 현재 선택입니다.
이름과 연결 모델 수를 먼저 확인하고 **저장 버전·모델 근거**에서 전체 ID와
해시를 볼 수 있습니다.

검사 이력을 선택하면 **검사 당시 저장본**을 따로 보여줍니다. 이 기록은
실행 때 보관한 버전·장치·체크포인트 근거입니다. 현재 모델을 바꾸어도 과거
기록의 근거를 현재 값으로 대체하지 않습니다. 옛 기록에 근거가 없으면
미기록이라고 표시합니다.

이 화면 정리는 현장 모델 성능이나 사람의 최종 수락을 대신하지 않습니다.
구현·실제 화면 검사·원격 CI·설치본 업데이트 결과는 별도로 기록합니다.

실제 화면·검사 결과와 미검증 범위는 [이번 검증 기록](verification/2026-11-16-product-workflow.md)에 있습니다.
