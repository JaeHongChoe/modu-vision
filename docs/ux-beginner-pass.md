## 8차 (2026-10-20) · 실제 데이터로 가져오기 점검

사용자 보유 데이터(현장 반입 부적합 이미지, 세라믹 표면 LabelMe 폴더, QC LabelMe 폴더, 실험 출력 폴더)를 스크래치 앱에 읽기 전용으로 가져와 확인했습니다.

| 발견 | 조치 |

- 예제 프로젝트가 정답 확인 전 흐름 평가를 "0장 · 미검 0 · 과검 0"으로 보고했습니다. 정답 확인 전이라고 말합니다(예제가 사람 대신 정답을 확정하지는 않음).

확인: 렌더러 테스트 1510개 전체, 단계 완료·근거 단계 단위 테스트, 영향 보고서 테스트(CI 두 목록에 추가), 브라우저 스펙(학습·평가·흐름·예제·검사·라벨링).

정정(2026-10-20 기능 점검): 처음에 "브라우저 스펙 77개 통과, 8개 실패, 실패는 CI에서 실행"이라고 적었으나 틀렸습니다. 로그를 다시 세면 70개 중 64개 통과, 6개 실패였고, 6개 모두 모델 가중치나 보존 모델 바인딩이 필요한 `@owned-model` 스펙입니다. 호스팅 CI는 `--grep-invert @owned-model`로 이 스펙을 빼고 돌리므로 CI에서도 실행되지 않습니다. 가중치가 있는 로컬 실행 결과는 `docs/functional-audit-fixes.md`에 적었습니다.

## 남은 것

- 이상 탐지 가져오기의 결함 이름 파일 안내는 데이터 준비도 패널에 있습니다(가져오기 요약 자체에는 아직 없음). 전체 수가 줄어든 것으로만 보입니다.
- 노드 LED 상태 글자(BUSY·FAIL·REVIEW·SKIP)는 스펙이 읽어 영어로 남았습니다. 오른쪽 속성 패널은 접지 않았습니다.
- 브라우저 모드에는 폴더 선택 창이 없습니다(경로 입력란으로 대체). 고급 설정 항목의 전문 용어는 남아 있습니다.
- CI: #7(main 기존)·#8(타이밍) 항목은 이 브랜치와 무관하게 남습니다.
