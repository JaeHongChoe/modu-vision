## 남은 것

- 5단계 흐름 평가는 이미지별 "명시적 정답"을 요구합니다. 폴더 라벨(OK/NG)이 있어도 자동으로 정답으로 쓰지 않으므로(검토 의무 유지) 초보자는 "정답 확인 0/12"를 보게 됩니다. 라벨에서 정답을 한 번에 채우는 검토 흐름은 별도 설계가 필요합니다.
- 이미 저장된 플로우의 노드·연결 이름은 저장 그래프 데이터라 그대로입니다(새로 만드는 플로우는 한국어 템플릿).
- 브라우저 모드에는 폴더 선택 창이 없습니다(데스크톱 앱 전용). 고급 설정 항목의 전문 용어는 남아 있습니다.
- `.venv`(FastAPI 0.108)에서는 `test_original_owned_*`·원격 실행 테스트가 환경 탓에 실패합니다(main HEAD도 동일, CI 목록 밖). CI의 `test_required_flow_current_source_cohort`(`flowchart_engine.py` 크기 핀)와 `test_service_s6_07`·`test_source_ci_model_lanes`(워크플로 잠금)는 main과 같은 상태로 이 브랜치와 무관하게 실패합니다.
