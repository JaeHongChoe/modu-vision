# 학습 전에 입력 흐름 준비하기

3단계 첫 화면의 **학습 흐름 준비**에서 모델에 넣을 입력을 설정합니다. 5단계는 학습된 모델을 연결해 검사·판정 흐름을 완성하는 단계입니다.

1. 1단계에서 자료와 클래스를 불러오고 학습·검증·시험 분할을 저장합니다.
2. 3단계에서 필요한 고정 입력 규칙을 추가합니다. 순서는 위·아래 버튼으로 바꿀 수 있습니다.
3. 실제 이미지를 선택하고 **실제 입력 미리보기**로 원본과 준비한 입력을 확인합니다. 영역 분할은 정답 마스크도 같은 좌표로 바뀝니다.
4. **규칙 저장** 후 학습합니다. 저장하지 않은 편집은 학습에 적용되지 않습니다. 기존 입력으로 돌아가려면 규칙을 비우고 저장합니다.

현재 지원 작업은 **이미지 분류·영역 분할**입니다. 고정 ROI 자르기, 90도 단위 회전, 밝기·대비 조절, 크기 조절을 순서대로 연결할 수 있습니다. 검출·OCR·방향·이상 탐지 등은 기존 입력 경로를 유지하며, 지원하지 않는 작업에 새 규칙을 넣으면 오류로 알려 줍니다.

고정 입력 규칙은 학습·검증·평가·저장 검사 흐름과 내보낸 검사기에 함께 적용됩니다. 모델의 최종 입력 크기와 내부 정규화는 별도로 유지하며 중복 적용하지 않습니다. 무작위 증강은 train에만 적용합니다. ROI 밖은 검사 범위에 포함되지 않으며, 영역 분할 결과는 관측한 범위에서 원본 좌표로 되돌립니다.

규칙은 버전·순서·해시로 저장 모델과 연결됩니다. 기존 원본·확정 라벨·모델·평가를 덮어쓰지 않습니다. 새 규칙으로 학습하려면 새 작업을 시작하며, 이전 모델은 이전 규칙으로 계속 실행됩니다. 이전 모델에 새 규칙을 몰래 끼워 넣지 않습니다.

입력 경로가 같다는 검사와 실제 불량 검출 성능·현장 운영 수락은 별개입니다. 목표 장치의 실제 내보낸 검사기로 시험한 결과가 있어야 패키지나 장치 검증을 완료로 기록할 수 있습니다.
