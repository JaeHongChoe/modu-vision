2. 실제 브라우저 이미지 디코딩·첨부 미리보기와 높은 추론 강도를 선택. 제어된 공급자 요청 두 번에 같은 바이트 해시·문맥·강도와 서로 다른 1회 grant가 전달됨을 확인했다. 외부 공급자 요청은 없었다.
3. 선택 가능한 수동 계획의 거절/확인·실행 중 중단·폴더 선택 취소·재로그인·설정 복원·재개·이전 기록 보존·새 요청을 확인했다. 분할/가져오기를 중복하지 않았다. 좁은 화면·두 테마·키보드 초점도 해당 경로에 포함했다.

POSIX 원본 Popen의 유효한 생성 시각·부모·PID·그룹·세션을 확인한 이 경계만 명시적 대기로 두고, 기존 관측 루프 안에서 실제 비어 있지 않은 명령줄이 불변 실행 인수와 정확히 일치할 때 승인한다. 승인 직전 새 Process로 명령줄·신원을 다시 확인한다. 대기 중 신호·자식 등록은 없으며, 다른 명령줄·세대·부모·그룹·세션·PID·읽기 오류·기존 미확인은 계속 거절한다. 끝까지 확인되지 않으면 스캔이 비거나 종료 코드가 0이어도 성공으로 바꾸지 않는다. 기존 기한·취소·신호·관측 기회를 유지하며 새 실행·대기 루프·상한 증가를 추가하지 않았다.

## 지원 범위와 남은 실제 검증

- 새 고정 입력 규칙은 분류·영역 분할부터 지원한다. 검출·OCR·회전·이상 탐지 등의 비어 있지 않은 새 규칙은 명시적으로 거절한다. 이전 입력 경로는 유지한다.
- 사용할 확정 라벨이 있으면 남은 초안 때문에 전체 실행을 막지 않는다. 초안만 있는 경우 이를 독립 정답이나 사람 확정으로 바꾸지 않는다. 별도 기계 라벨 버전의 자동 materialization은 후속 범위다.
- 독립 정답·저장된 품질 정책·비교 근거가 없으면 품질 판정은 입력 필요로 남는다. 가능한 평가·추론 결과와 품질 통과를 구분한다.
- TrainingController 소스가 바뀌어 F025의 success/invalid와 F027의 success, 총 3개 과거 native DINO GUI 기록은 현재 검증으로 재사용하지 않는다. [이전 기록과 소스 해시](receipts/2026-10-29-training-input-action-source-provenance-delta.json)를 그대로 보존하고 현재 항목은 pending으로 분리했다. 전체 기능 accepted 수는 0이며, 원장 무결성 검사와 실제 학습 수락은 다르다.
- 새 실제 ChatGPT 이미지 요청은 실행하지 않았다. 실제 계정의 이미지 수신과 모델 응답, 사용자 프로젝트의 학습·현장 품질, 설치 앱/웹 교체, 대상 OS/장치 패키지·운영 인수는 별도 검증이다.
- 기존 Work 브라우저 권한 오류를 우회하지 않았다. 위 화면 검사는 사용자 프로필과 별개인 저장소 소유 Playwright fixture다.
- strict UI 정적 감사는 기존 전역 textarea/scrollbar 부채 **38건**을 보고한다. 새 native select의 소유권은 문서화했으며 새 unresolved 항목은 없다. 생성된 light-theme의 변경은 기존 색상 사용 횟수 주석뿐이다. 전체 제품의 접근성 준수를 선언하지 않는다.
