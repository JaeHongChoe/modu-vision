# 작업을 수행하는 ChatGPT 도우미 검증 기록

## 변경과 사용 흐름

도우미는 연결된 ChatGPT에 앱의 지원 기능과 현재 화면 상태를 제공하고, 사용자의 요청을 최대 24단계 계획으로 제안할 수 있다. 사람이 실제 작업·입력값을 확인하면 앱의 실행기가 그 계획을 차례대로 수행한다. 계획 승인 도구는 모델에 제공하지 않는다.

프로젝트 생성, 사용자가 선택한 폴더 가져오기, 분할 저장, 학습 설정, 라벨 초안 생성, 학습 시작, 모델 평가, 단일 모델 흐름 저장, 저장 흐름 평가, 시험 이미지 검사, 보고서 저장, 단계 이동을 기존 서비스와 화면 처리기에 연결했다. 지원하지 않는 학습 방식이나 보고서 범위, 필요한 모델·자료가 없는 경우에는 이유와 확인할 화면을 보여 준다.

계획 카드에는 진행 단계와 저장 결과를 표시하며, 일시정지와 검토 후 이어가기를 제공한다. 이미 시작한 학습을 일시정지가 취소하지 않는다. 라벨 채택, 정답 확정, 최종 모델·흐름 승인과 운영 배포는 사람이 수행한다. 저장된 정답을 사람이 변경한 뒤 흐름 재평가를 재개할 때에는 원본 바이트·모델·규칙이 같은지 확인하고 새 시험 묶음과 평가의 실행 의도·번호를 먼저 기록한다.

## 실행과 복원

작업 기록은 기존 계정/데스크톱 권한과 CSRF 검사를 사용하며, 프로젝트 선택 전에도 해당 서버 작업공간과 로그인 사용자의 기록만 준비한다. 물리적으로 다른 등록 프로젝트 위치와 실행 문맥은 합치지 않는다. 계획의 원래 승인과 입력은 불변이며, 현재 계정·모델·원본·설정과 맞지 않으면 이어서 실행하지 않는다.

각 단계의 실행 의도를 먼저 저장한다. 응답을 잃으면 기존 작업 번호로 저장 결과를 확인하고, 증거가 없으면 확인 대기로 남긴다. 사람 검토 전에는 재개하지 않는다. 미실행이 확인된 사람 대기의 재개는 별도의 원자적 claim으로 한 창만 소유권을 얻는다. claim 응답 소실이나 경쟁 요청은 다시 실행하지 않는다. 일반 자동 진행과 도우미 실행은 동일 프로세스의 단일 쓰기 lease를 사용한다.

작업 저장소는 macOS/Linux의 개인 권한·symlink 거절·atomic replace·파일 잠금을 사용한다. 새 작업 실행의 Windows 지원은 준비 중이며, 미지원 환경은 저장 전 501로 명시적으로 거절한다. 기존 도우미 연결 기능의 지원 범위를 새로 넓혔다는 뜻은 아니다.

## 증거의 범위

공급자 응답은 제어된 로컬 fixture이고, 파일·분할·설정·작업 원장은 실제 renderer와 backend를 사용한다. 실제 ChatGPT 로그인·유료 요청·외부 이미지 전송은 실행하지 않았다. 실제 모델 품질, 모든 운영체제, 현장 정답, 처음 사용자의 작업 시간 또는 전체 제품 수락을 증명하지 않는다.

설치된 사용자 앱, 실제8443/기존59443, 원본 프로젝트·이미지·라벨·모델, 다른 checkout과 자동화는 변경하지 않는다. 새 작업은 ca52 위의 별도 기능 브랜치에 있으며, PR18의 전체 회귀와 새 기능 검증은 서로 다른 head의 증거다.
