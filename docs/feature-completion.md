# 기능 구현 및 검증 범위

기준일: 2026-09-30

이 문서는 승인된 선행 작업과 1~4차 기능 범위를 현재 코드, 회귀 테스트, 실제 실행 결과에 맞춰 정리한다. 기능 구현, 실행 성공, 모델 품질, 운영 승인, 장비 수용은 각각 별도로 판단한다. 비공개 입력, 모델 파일, 상세 실행 기록은 저장소에 포함하지 않는다.

## 상태 읽기

| 표시 | 의미 |
| --- | --- |
| 구현 | 저장·실행·오류 처리와 해당 화면 또는 API 경로가 있다. 아래 지원 범위 안에서의 구현을 뜻한다. |
| 실제 실행 확인 | 실제 입력으로 명시된 경로를 실행했다. 대표 데이터 성능이나 현장 운전을 뜻하지 않는다. |
| 계약·모의 검증 | 회귀 테스트, 생성한 입력 또는 모의 인터페이스로 확인했다. 실장비·실제 정답 수용은 별도다. |
| 제공하지 않음 | 실행 경로가 없거나 현재 지원 범위에 포함되지 않는다. |

## 선행 작업: 데이터와 프로젝트

| 기능 | 구현 상태와 연결 | 검증 및 제한 |
| --- | --- | --- |
| 프로젝트 생성·열기·데이터 출처 | 프로젝트별 라벨·분할·모델·검사 기록 격리 | 같은 입력을 사용하는 프로젝트의 독립 편집·복구 회귀 검증. 원본을 자동 수정하지 않는다. 원본 이미지 내용 또는 결합한 불변 스냅샷의 무결성이 바뀌면 해당 결합 실행을 차단한다. 라벨 검수 후 기존 모델을 새 평가 입력으로 재평가할 수 있다. |
| 이름 있는 라벨 세트 | 생성·복제·목록·전환, 주석과 이력 격리 | 전환·재시작·모델 복구 검증. 세트 삭제와 다중 사용자 권한 관리는 제공하지 않는다. |
| 이미지 식별·메타데이터 | UUID, 내용 해시·버전, 크기, 자유 태그, 제품·Lot·그룹 | 원본 경로와 식별자를 보존하며 페이지·필터 밖 이미지도 정확한 경로로 연다. 메타데이터를 폴더 이름에서 추정하지 않는다. |
| 검수·감사·충돌 | 미작업·검토 필요·승인 상태, 검토자, 수정 버전, 이력 | 주석·마스크·원본 변경 시 승인 무효화. 오래된 수정과 검토 충돌을 거절한다. 별도 사용자 계정·권한 서버는 없다. |
| 일괄 메타데이터 편집 | 선택 이미지 또는 필터 결과의 태그·제품·Lot·그룹 변경 | 하나라도 수정 버전이 다르면 전체 변경을 중단한다. 개별 승인까지 일괄로 대체하지 않는다. |
| 그룹 분할·중복 확인 | 제품·Lot·그룹과 동일 내용 묶음을 train/val/test에 배정 | 미리보기·적용·중복 누출 검사와 실제 학습/평가 로더 연결. 원본 경로는 유지한다. |
| LabelMe·COCO·YOLO 교환 | 가져오기 미리보기·충돌 정책·적용, 내보내기 | 지원 bbox/polygon의 소수 좌표 왕복 검증. COCO RLE/crowd, brush 마스크 교환, 손실 없는 표현이 불가능한 회전 변환은 명시적으로 거절한다. |
| 데이터 버전 | 이미지·라벨·분할 해시와 불변 스냅샷, 검증·복원 | 학습 입력에 버전·라벨세트·분할 식별자 결합. 복원 후 재검수가 필요하며 이후 감사 이력을 지우지 않는다. |
| 프로젝트 백업·새 위치 복원 | 중첩 주석 범위, 버전·모델·플로우·이력 연결 복원 | 경로 재연결과 해시 검증. 원본 라벨 스냅샷은 바이트를 보존하며 모델 식별자를 유지한다. |
| 출처 통합 조회 | 이미지→라벨→분할→모델→플로우→검사 결과 연결 | 현재 프로젝트의 ID·버전·해시를 표시한다. 다른 프로젝트의 결과를 섞지 않는다. |

## 1차: 검사 플로우와 실행 근거

| 기능 | 구현 상태와 연결 | 검증 및 제한 |

| 편집 이력·초안·실행 버전 | Undo/Redo, 버전 저장·선택, 미완성 초안 저장 | 미완성 그래프를 프로젝트·라벨세트 전환 때 보존한다. 초안 저장은 실행 가능한 저장 버전이나 운영 승인으로 승격되지 않는다. |
| 5단계→6단계 | 검증된 저장 그래프와 정확한 모델 참조로 단일/일괄 실행 | 이미지별 결과, 노드 추적, 원본 좌표, 그래프·모델 해시를 보존한다. 모델이나 ROI가 없으면 REVIEW/오류다. |
| 전체 플로우 내보내기 | 그래프·체크포인트·실행 코드·파일 해시 목록 | 앱과 패키지의 판정·좌표·마스크·분기 근거 비교. 실행 장치별 수용은 별도다. |

## 3차: 라벨 후보와 모델군

| 기능 | 구현 상태와 연결 | 검증 및 제한 |
| --- | --- | --- |
| 완료 모델 보조 라벨링 | 단일/일괄 후보 생성, 클래스 키워드 제한, 검토·채택·거절 | 완료 모델의 실제 추론 결과를 사용한다. 후보 채택은 원본과 라벨 수정 버전을 다시 확인한다. |
| 텍스트 영역 제안 | 로컬 Grounding DINO를 사용하는 별도 의미 기반 공급자 | 실제 체크포인트 CPU 추론과 네이티브 후보 채택 확인. 선택 의존성과 로컬 가중치 설치가 필요하며 자동 다운로드는 없다. 영어 설명 지원이며 한국어·미세 결함 품질은 미승인이다. |
| 예시 이미지 제안 | 선택 영역을 사용하는 OpenCV 템플릿 유사도 | 실제 위치·크기와 후보 검토를 제공한다. 비슷한 배율·방향과 텍스처가 필요하다. 의미 이해로 표시하지 않는다. |
| 일반 분류·검출·분할·이상탐지 | 기존 학습·평가·플로우·내보내기 경로 | 고정 preset 기반이다. 원격 일반 모델 학습·중단·부모 모델 재학습 실행을 확인했다. 모든 작업/장치 조합의 검증은 아니다. |
| Patch Classification | 좌표·라벨·해시 패치 manifest → 학습 → 평가 → 검사 → 패키지 | 로컬 경로 및 실제 입력 실행 확인. 원격 패치 학습은 제공하지 않는다. |
| OCR | 명시적 문자 정답 → CTC 학습 → 문자 평가 → expected-text/regex → 플로우·패키지 | 실제 문자 정답이 없어 계약·모의 입력만 검증했다. OCR 정답을 이미지나 파일명에서 만들어내지 않았다. |
| 회전 객체 검출 | LabelMe polygon에서 OBB 생성, 다중 객체 학습·평가·추론 → 플로우·패키지 | 실제 입력 CPU 학습·평가·원본 좌표·패키지 동등성 확인. 고정 객체 슬롯 용량이며 현재 manifest는 객체 없는 이미지를 지원하지 않는다. 실제 모델 품질·회전 형상 승인은 없다. |
| 이상탐지 공간 근거 | 분류/영역 모드, 실제 heatmap·마스크 → 픽셀 평가·Blob | 실제 정답 마스크가 있어야 픽셀 지표를 계산한다. 없는 결함 마스크를 정상으로 채우지 않는다. |
| 학습형 영상 개선 | 별도 입력/정답 쌍 → 학습 → 원해상도 평가 → enhancement 전처리·패키지 | 쌍의 실제 픽셀·분할 해시를 검증한다. 실행 확인과 개선 여부를 구분한다. 최근 실제 평가에서 개선이 확인되지 않았다. |
| 학습형 GAN | 원본 결함 crop → 학습 → test 진단 → 후보 생성·검토 → train 전용 채택 | 검증·시험의 실제 입력을 보존한다. GAN은 생성 데이터 워크플로이며 검사 OK/NG 모델 노드가 아니다. 별도 생성 패키지를 제공한다. |
| 부모 모델 재학습 | 호환 작업·구조·클래스·해시·부모 계보 확인 | 지원되는 로컬/원격 경로에서 후보를 학습한다. 성능 유지와 교체는 같은 holdout의 평가 및 별도 승인으로 판단한다. |

### 설치·패키징 경계

현재 데스크톱 패키지는 Python 백엔드 코드를 포함하지만 외부 Python 실행 환경과 필요한 라이브러리를 사용한다. 새 컴퓨터에서 추가 환경 준비 없이 동작하는 완전 자급형 설치 프로그램으로 검증하지 않았다. Windows 파일 잠금 호환 경로는 회귀 테스트로 확인했으며 Windows 실 OS 실행은 미검증이다. 전체 플로우·GAN 생성 패키지도 해당 Python 의존성을 설치해야 한다. 설치 파일 생성, 실행 성공, 새 환경 호환성, 모델 품질은 각각 별도 수용 조건이다.

## 제공하지 않는 확장 범위

- 소량 라벨 변경만으로 자동 학습·추천 모델 갱신, 자동 재학습·승격·현장 적용 루프.
- 구조·초매개변수 자동 탐색과 HPO. 현재 preset 및 명시적 파라미터 선택을 사용한다.
- DDP·다중 GPU 분산 학습 및 다중 라인 자동 관제. 공유 GPU 예약·대기열과 구분한다.
- FP16 변환·양자화·자동 경량화. 지원하지 않는 export 옵션은 명시적으로 거절한다.
- 다중 사용자 계정·역할 권한·작업 배정 서버와 라벨 세트 삭제.
- 범용 Edge 하드웨어, SDK별 현장 카메라/PLC 통합, 실제 장비의 택트타임·장시간 안정성 수용.

수동 검수 후 명시적으로 재학습하고 holdout을 비교·승인하는 경로는 구현 범위에 포함된다. 자동 재학습·분산 학습으로 표현하지 않는다.
