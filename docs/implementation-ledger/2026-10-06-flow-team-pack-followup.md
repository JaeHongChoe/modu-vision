## Whole-flow review (S4-14)

An explicit named, immutable policy revision binds a current completed full-graph
evaluation, all known truth, distinct heldout content, model/checkpoint hashes,
sample minima and escape/overkill/review limits. A reviewer reason and unchecked
manual confirmation are required. CAS selection, historical selection, reopen,
truth/graph/model changes and membership revocation are checked without rewriting
old review records. A graph review does not create truth or accept a device.

Package qualification rechecks the exact full graph, checkpoints, current model
approvals and parity on the same reviewed heldout inputs. It returns separately
trusted review metadata; it does not change package bytes. Managed apply/rollback
checks that metadata before and after runtime acknowledgement. The current
command actor's membership is rechecked separately from the review issuer.
Denied HTTP apply/rollback requests refuse before creating service state.
Sealed restart and failure recovery remain distinct from new central commands.
Legacy model-only releases retain their compatibility path when no graph review
exists; they are not relabeled as whole-flow reviewed releases. A current graph
review cannot be bypassed by omitting its revision.
