## 모델 기본값과 실제 입력 검증

이미지 분류·패치 분류·영역 분할은 **실제 DINOv3 사전학습 가중치**를 사용하고, 일반 객체 검출은 **YOLO 사전학습 가중치**를 기본으로 한다. 사전학습 파일이 없거나 형식·해시가 맞지 않으면 준비 오류를 표시한다. 무작위 초기화를 사전학습으로 표시하지 않는다.

실제 공급 이미지 6장에서 원본 좌표의 64×64 크롭 12개를 만들었다. 크롭은 리사이즈하지 않았으며 원래 주석을 좌표로 잘라 연결했다. 다음 10종 모두 CPU에서 실제 준비·최적화·평가·추론·저장·REST 재열기를 실행했다.

| 모델 | 실제 실행 범위 |
| --- | --- |
| 분류·분할·패치 분류 | 실제 DINOv3 특징과 학습 헤드, 시험 데이터 평가, 패키지 검사 |
| 일반 검출 | 실제 YOLO 사전학습, 학습·평가·패키지 검사 |
| 이상탐지 | 실제 DINOv3 합성 결함 경로, 평가·패키지 검사 |
| OCR | 문자 정답 준비, 실제 CTC 학습·평가·문자 규칙·패키지 검사 |
| 회전 검출·정방향 보정 | 실제 모델 학습·평가·형상·좌표 전달·패키지 검사 |
| 이미지 개선 | 입력·정답 쌍 학습, 품질 지표·추론·패키지 검사 |
| 결함 생성 | 실제 GAN 학습·평가·원본 연결 합성 후보·사람 검토. 검사 판정 노드로 취급하지 않음 |

9종 검사 모델은 독립 실행 패키지를 실제 CPU에서 실행했고 GAN은 원본에 합성한 검토 후보를 생성했다. 실제 최적화가 진행된 작업을 취소한 뒤 `cancelled`와 우승 모델 없음도 확인했다. 해시·작업·평가·패키지 식별자는 [실제 입력 manifest](P08-real-input-manifest.json)에 있다.

이 검증의 OK는 배경 크롭 대조군이고 OCR 문자는 통제한 정답이며 회전은 통제한 방향이다. 실제 정상 제품, 자연 문자, 실제 다양한 회전 분포의 품질을 입증하지 않는다. 짧은 CPU 기능 학습 결과를 양산 모델로 승인하지 않았다.

원본은 이미지 88개·주석 83개, 총 **171개 파일**이며 전후 SHA-256 목록이 일치한다. 원본과 공급 주석은 변경하지 않았다.

## 데스크톱 앱에서 직접 확인한 흐름

- 원본 데이터 가져오기, 활성 라벨 세트 통계, 프로젝트·분할 다시 열기.
- 재열기 시 과거 도형 개수를 이미지 수로 표시하던 회귀 수정: 원본 88장·라벨 완료 80장·미라벨 8장, 같은 클래스의 여러 도형은 한 이미지로 집계한다. 통계에서 미라벨 8장 필터로 이동하는 동작도 앱에서 확인했다.
- 이미지별 태그·검토 상태, 라벨 세트 복사, 검수 플래그 저장.
- 줌 확대·축소·맞춤·1:1, 브러시·지우개·Undo/Redo·별도 라벨 세트 저장.
- 10종 모델 허브와 DINOv3 기본값, 완료 작업의 실제 CPU 장치 표시. 현재 호스트의 Metal 상태와 학습 기록을 구분한다.
- 실제 완료 모델 평가, FN 필터·픽셀 분석·점수·ROC, 재평가 결과 저장.
- 포트로 고정 ROI→분할→판정 연결, 잘못된 연결 안내, Undo/Redo, 자동 배치, 새 플로우 버전 저장.
- 실제 ROI 이미지 검사와 노드별 중간 결과, 시험 이미지 4장 일괄 검사.
- 모델 원판정과 작업자 NG 판정을 각각 저장하고 재열기, CSV·JSON 4행과 식별자·해시 읽기 확인.
- 저장한 DINOv3 ROI 플로우를 앱에서 내보내기: **141개 파일 생성, 실제 입력에서 앱 엔진·독립 패키지 결과 일치**, 네이티브 SDK 소스 10개 포함.
- 종료 후 프로젝트·평가·플로우·검사 이력 복원. 파괴된 창의 헤더 처리 예외에 대한 회귀와 정상 종료 확인.

이 목록은 직접 확인한 동작을 나타낸다. AI 모델 설정·모든 줌 조합·모든 장비 어댑터의 모든 UI 조합을 클릭했다고 주장하지 않는다. SAM2는 별도 실제 원본 크기 이미지/API와 CPU 모델로 검증했다. 텍스트와 이미지의 결합 인식 품질은 선택한 외부 모델·가중치와 실제 제조 데이터로 추가 실증해야 한다.

저장 실행·플로우·모델·입력 해시와 재열기 근거는 [앱 검증 manifest](NATIVE-workflow-manifest.json)에 기록했다. 원본 파일명·로컬 데이터 경로·화면 캡처·모델 파일은 공개 manifest에 포함하지 않는다.

## 남은 인수 조건

구현에서 제외한 항목은 없다. 다음은 장비·현장 데이터·설치 환경에 따른 **인수 검증**이다.

- CUDA GPU·실제 MIG·Jetson·Intel GPU/NPU·Windows/Linux 설치 환경의 실행과 장치별 정밀도 수치.
- 실제 카메라·PLC·MES 장비, 공급 프로토콜·타임아웃·재전송·생산 인터록의 연동 시험.
- 실제 정상/불량 정답, 자연 OCR, 다양한 회전·제품·Lot·조명 조건의 제조 품질 및 임계값 승인.
- 외부 foundation 모델별 텍스트·이미지 프롬프트 인식 품질, 대형 이미지·실제 다중 사용자 부하, 모든 UI 조합의 인수 시험.

공개 소스·새 문서에는 조사 업체명, 비공개 발표자료, 원본 데이터 경로, 서버 자격증명을 넣지 않는다. 기존 Git 이력은 보존한다. 과거 커밋 메시지·브랜치 이름을 지우는 이력 재작성은 수행하지 않았다.
