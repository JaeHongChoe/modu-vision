## Implementation

- `backend/engine/training_engine.py` initializes an independent explicit-output workspace without activating/changing the GUI project. Each workspace binds one canonical source and task. Native originals stay read only. Every preparation owns its labels, splits, actual family input and immutable version; failed revisions preserve previous preparation.
- All ten families dispatch into the actual P04 measured coordinator: genuine pretrained DINOv3 classification/Patch/segmentation, YOLO detection, normal-only DINO synthetic anomaly, learned angle CNN, CTC OCR, oriented box detector, residual enhancement and defect GAN. Search varies only registered applied controls. Family metrics/direction and latency scope are declared; no shared generic accuracy is fabricated.
- External samples/COCO/LabelMe import retains safe relative source paths, partitions, native coordinate validation and SHA binding. Flat classification and anomaly labels produce owned class/normal layouts. OCR/OBB/Rotation/GAN/Patch use actual owned family preparation. Enhancement supports seeded noise/clean pairs and explicit native before/after pairs with both source hashes and requested partitions.
- `backend/training_cli.py` supplies capabilities, prepare, quick/search/parent training, persistent status/cancel, evaluation and per-image output. Foreground progress is JSONL; background is an independent local subprocess with a durable log. Delivered selected configuration can be reused; fast retraining keeps parent structure/settings and starts a new optimizer.
- `backend/api/routes_training_engine.py` exposes the same operations under `/api/engine` for an external UI. Shared role/source/output scope gates retain the selected authorized project. Output downloads verify SHA and supply `X-Content-SHA256`. API failures reject unsafe paths, unsupported controls, invalid budgets, incompatible structures and unavailable devices.
- Completed output contains actual model bytes, model metadata, reusable configuration, heldout evaluation JSON, source-linked per-image predictions and an artifact SHA/size manifest. Result and generated-image revisions are immutable, including hashed GAN review outputs; status verifies their bytes and REST can download each output. Evaluation/prediction uses the delivered checkpoint and adjacent immutable metadata, with canonical original paths plus owned evaluation paths. Cancellation, exact process identity, a process-safe execution claim, old label revisions and completed artifact reopening are persisted.
- Usage and all family label contracts are documented in `docs/training-engine-cli-rest.md`; main router and shared authorization prefix are integrated.
