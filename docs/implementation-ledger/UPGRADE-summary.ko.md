## 최종 확인

- 백엔드 전체: 1,555 통과, 27 환경 의존 항목 건너뜀. 프런트엔드 전체: 115 통과. 타입 검사·빌드 통과. 네이티브 패키지 검사: 40 통과.
- 실제 이미지로 학습 준비, CPU 학습·평가, 취소, 정확한 과거 모델 복귀, ROI 실행·저장·완전 재시작 복원, 파생 이미지 생성, 진단자료 저장, 로컬 통신 ACK를 확인했습니다.
- CLS·SEG·Patch는 실제 DINOv3 사전학습 가중치, 검출은 YOLO로 소규모 CPU 학습·체크포인트 재로딩·추론을 확인했습니다. 제조 품질을 승인하는 시험은 아닙니다.
- 원본 파일 171개의 경로·해시가 모두 유지됐습니다. 실제 GUI 관찰, 저장 기록과 로그 해시는 `UPGRADE-integration.md` 및 담당별 ledger에 있습니다.

## 검증 상태 읽는 방법

`integration_verified`는 구현과 통합 시험이 완료됐다는 뜻입니다. 각 요구사항의 `gui`, `persist`, `reopen`, `failure`, `handoff`는 직접 확인한 범위만 `passed`로 표시했습니다. 전체 경로를 직접 누르지 않은 항목은 `pending`으로 남겨두었습니다.

실물 GPU/MIG/NPU/Edge·카메라·PLC/MES, 외부 VLM, .NET 실행, 서명된 배포·자동 업데이트는 해당 장비·환경·설정이 갖춰진 뒤 실제 실행 검증이 필요합니다. 현재 제공되는 지원 설정과 검증 화면을 운영 승인으로 표시하지 않습니다. 기존 원격 커밋 이력은 보존합니다.
