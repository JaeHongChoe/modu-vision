- DAG rules: required detector class counts, missing/excess NG, untrained/incomplete

  Unverified mm arithmetic cannot be presented as a qualified physical verdict.
- Workspace: selected-subgraph save/reuse, explicit target model/class mapping,
  draft save/reopen and Undo/Redo are exercised in Chrome and development Electron.
  Unconnected template ports are displayed for explicit wiring.
- Offline trust: pinned Ed25519 authority, exact target/protocol/version and artifact
  inventory, revocation/downgrade refusal, stable bounded manifest reads, streaming

  platform signing are still required. Runtime-pack inventory does not install packs.

  writes using forward recovery, CAS, journal completion and an increasing fence.
  Historical converters and live worker/uncertain lease adoption remain missing.
- Process control: actual spawn DataLoader workers are stopped while an unrelated
  process remains alive. Windows native execution is not inferred from that result.
- Capacity: 100k metadata paging, a separate 10k×8k original image decode, durable
  queue duplicate/backpressure/reopen controls and actual bounded CPU endurance.
  A frozen 72-hour run is live; elapsed time is not a completed soak.
- CUDA: actual optimizer/AMP/RNG next-step exact resume and changed-recipe refusal
  run on an owned GPU reservation. This is a small CUDA component control, not
  the full native AutoDL/DDP workflow qualification.
- Faults: ten scenarios select real contract tests/JUnit results; local controls
  are distinguished from target service/installer/physical-device qualification.
- Legacy scope: all 156 records retain owners and a static action inventory.
  Inventory coverage is not runtime action coverage; unexecuted scenarios stay pending.
