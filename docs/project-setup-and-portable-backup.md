# 프로젝트 설정 템플릿과 이동

프로젝트 관리의 **프로젝트 설정 템플릿**에서 현재 설정을 읽고 JSON을 복사해 다른 환경에 붙여 넣을 수 있습니다. 새 프로젝트 이름과 새 폴더를 입력하면 새 ID로 생성합니다. 검사 유형, 학습 프리셋, 태그 색상, 보존 정책만 재사용합니다. 원본 이미지, 라벨, 모델, 플로우, 결과, 핀, 권한과 승인 기록은 템플릿에 포함하지 않습니다. 서버는 허용 필드, 내용 해시, 값의 범위를 생성 전에 검증합니다. 기존 폴더는 템플릿 생성 대상으로 사용하지 않습니다.

전체 작업 이동에는 **프로젝트 백업 → 백업에서 복원**을 사용합니다. 파일별 크기와 SHA-256, 원본/라벨셋 지문, SQLite의 커밋된 내용을 기록하고, 새 폴더의 모든 파일을 검증한 뒤 경로와 지문을 다시 연결합니다. 원본과 기존 복원 폴더는 덮어쓰지 않습니다. 검사 이력은 복원된 작업 공간에서 새 실행 ID로 연결되며, 원래 모델 결과와 검토 이력은 보존됩니다. 팀 검토와 실행 권한은 기존 복원 검증 규칙에 따라 재확인이 필요합니다. 준비된 OCR/회전 박스 정답의 경로가 이동해도 해당 모델의 준비 데이터와 동결된 학습 근거를 검증합니다.

백업은 알려진 자격 증명 파일 이름, JSON/SQLite의 자격 증명 필드, private-key 표식, 자격 증명이 붙은 URL을 검사하고 값을 출력하지 않고 거절합니다. 임의의 바이너리나 인코딩된 비밀정보를 모두 찾아내는 DLP 검사는 아닙니다. 원본 이미지나 사용자 기록을 자동 수정하지 않습니다.

호스트 전용 서비스 토큰·프로세스·등록 정보와 네이티브 설치 파일은 백업에 실리지 않습니다. 장치 목록과 운영 이력은 유지하지만 fleet DB의 연결 토큰은 복사본에서 지웁니다. 복원된 서비스는 실행하지 않고 새 자격 증명으로 초기화하며, fleet는 연결 정보를 다시 설정하기 전 접속을 거절합니다. 기존 프로젝트의 연결 토큰은 그대로 유지합니다.

**보존기한·복구 보관함**은 관리 대상 아티팩트의 복구 가능한 이동과 원래 경로 복원을 제공합니다. 연결된 원본, 활성 배포, 검토 보류 등의 보호된 파일은 이동하지 않습니다. 설정한 용량 기준은 상태에 표시하며, 자동 영구 삭제는 실행하지 않습니다. 이 기능은 프로젝트 폴더 전체 삭제 기능이 아닙니다.

소프트웨어 검증은 합성 데이터의 실제 Chrome/macOS 개발 Electron, CPU 모델, 새 경로 복원과 저장된 바이트/실행 결과에 한정됩니다. 운영 환경이나 다른 서버의 이동, 모델 품질 승인, 설치본·실물 장비와 Windows 검증을 대신하지 않습니다.
