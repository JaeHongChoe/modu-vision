# 공동 프로젝트 서버

서버에서 최초 관리자 계정을 생성합니다. 비밀번호는 터미널에서 숨겨 입력하며 저장소에는 해시만 기록합니다.

```sh
python -m backend.accounts_cli --shared-auth-dir /srv/vision/accounts --username admin
python -m backend.main --host 127.0.0.1 --port 8000 --project-dir /srv/vision/projects --shared-auth-dir /srv/vision/accounts
```

다른 컴퓨터의 앱에서 **서버 자원 → 공동 프로젝트 서버**를 펼칩니다. HTTPS 주소 또는 SSH 터널의 localhost 주소로 로그인합니다. 예를 들어 SSH 터널은 `ssh -L 8000:127.0.0.1:8000 user@server`로 연결할 수 있습니다. 비밀번호와 세션 토큰은 앱 화면·프로젝트 JSON·로컬 저장소에 저장하지 않습니다. 연결을 끊거나 앱을 종료하면 앱의 세션 정보가 지워집니다.

관리자는 프로젝트와 사용자를 생성하고 프로젝트별 역할을 부여합니다.

| 역할 | 허용 작업 |
| --- | --- |
| viewer | 데이터·모델·결과 조회 |
| labeler | 라벨 작성·후보 검토·메타데이터 편집 |
| trainer | 라벨 편집·학습·평가·플로우 검사 |
| reviewer | 학습 작업과 라벨·모델 승인 |
| owner | 프로젝트 설정과 사용자 권한 관리 |

프로젝트 데이터 경로는 서버의 경로입니다. 각 요청은 로그인한 사용자의 프로젝트를 별도로 선택하며 파일·모델·진행 이벤트도 그 프로젝트 안에서 확인합니다. 학습용 SSH 계산 프로필과 공동 프로젝트 로그인은 별도 설정입니다. 일반 데스크톱 실행은 기존 로컬 프로젝트 방식으로 사용할 수 있습니다.

세션은 기본 8시간 후 만료됩니다. 관리자 생성은 서버에서 직접 실행하거나 프로세스 인증값으로 보호되는 최초 설정 API를 사용합니다. 외부 네트워크 연결에는 HTTPS를 사용하며 localhost HTTP는 로컬 실행 및 터널용입니다.
