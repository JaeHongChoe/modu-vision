# 공동 프로젝트 서버

서버에서 최초 관리자 계정을 생성합니다. 비밀번호는 터미널에서 숨겨 입력하며 저장소에는 해시만 기록합니다.

```sh
python -m backend.accounts_cli --shared-auth-dir /srv/vision/accounts --username admin
python -m backend.main --host 127.0.0.1 --port 8000 --project-dir /srv/vision/projects --shared-auth-dir /srv/vision/accounts
```

다른 컴퓨터의 앱에서 머리글의 **서버 관리**(간단히 보기에서는 더 보기 메뉴 안)를 열고 **공동 작업 서버**를 펼칩니다. 같은 창의 **서버 준비 방법**은 폴더·포트·관리자 이름·SSH 접속 대상을 받아 아래 명령을 그대로 만들어 줍니다. HTTPS 주소 또는 SSH 터널의 localhost 주소로 로그인합니다. 예를 들어 SSH 터널은 `ssh -N -L 8000:127.0.0.1:8000 user@server`로 열고 앱에는 `http://127.0.0.1:8000`을 입력합니다. 비밀번호와 세션 토큰은 앱 화면·프로젝트 JSON·로컬 저장소에 저장하지 않습니다. 연결을 끊거나 앱을 종료하면 앱의 세션 정보가 지워집니다.

관리자는 프로젝트와 사용자를 생성하고 프로젝트별 역할을 부여합니다.

| 역할 | 허용 작업 |
| --- | --- |
| viewer | 데이터·모델·결과 조회 |
| labeler | 라벨 작성·후보 검토·메타데이터 편집 |
| trainer | 라벨 편집·학습·평가·플로우 검사 |
| reviewer | 학습 작업과 라벨·모델 승인 |
| owner | 프로젝트 설정과 사용자 권한 관리 |

프로젝트 데이터 경로는 서버의 경로입니다. 각 요청은 로그인한 사용자의 프로젝트를 별도로 선택하며 파일·모델·진행 이벤트도 그 프로젝트 안에서 확인합니다. 학습용 SSH 계산 프로필과 공동 프로젝트 로그인은 별도 설정입니다. 일반 데스크톱 실행은 기존 로컬 프로젝트 방식으로 사용할 수 있습니다.

세션은 기본 8시간 후 만료됩니다. 관리자 생성은 서버에서 직접 실행하거나 프로세스 인증값으로 보호되는 최초 설정 API를 사용합니다. 외부 네트워크 연결에는 HTTPS를 사용하며 localhost HTTP는 로컬 실행 및 터널용입니다.

## 네트워크와 HTTPS

- 서버는 `--host 127.0.0.1`로 시작해 그 컴퓨터 안에서만 열고, 다른 컴퓨터는 SSH 터널로 접속하는 것을 기본으로 합니다. `0.0.0.0`으로 열지 마세요. 백엔드에는 TLS 옵션이 없어 그대로 열면 비밀번호와 세션이 암호화되지 않습니다.
- 터널 없이 접속하려면 서버 앞에 인증서를 가진 HTTPS 리버스 프록시를 두고 `https://` 주소를 씁니다. 데스크톱 앱은 이 컴퓨터(`localhost`, `127.0.0.1`, `[::1]`)가 아닌 `http://` 주소로는 로그인하지 않으며, 화면도 그런 주소를 입력하면 경고합니다.
- 브라우저로 접속하는 쿠키 세션은 설정된 HTTPS 출처에서만 열립니다.
- 공유 프로젝트는 관리자가 "프로젝트·계정 관리"에서 작업 종류(분류·객체 검출·영역 분할·이상 탐지)를 골라 만듭니다.

## OIDC 로그인 (아직 설정 경로 없음)

계정 저장소에는 OIDC 식별자 연결 기능이 있지만, 서버를 시작할 때 OIDC 제공자를 설정하는 옵션은 아직 없습니다. 조직 로그인(SSO)을 붙이는 일은 인증 경로를 바꾸는 보안 결정이므로, 제공자·리디렉션 주소·허용 도메인을 정한 뒤 별도로 진행합니다.
