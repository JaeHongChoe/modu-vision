# 자기 사진으로 처음 만드는 AI

모두비전은 사진에 무엇이 있는지 알려주고, AI가 처음 보는 사진에서도 찾는지 확인하는 작업 공간입니다. GPT 계정 연결 없이도 아래 버튼으로 진행할 수 있습니다.

## 시작할 일 고르기

상단의 **설정·도구 → 처음 시작 안내**를 엽니다.

- **예제로 해보기**: 합성 사진으로 별도 예제 프로젝트를 만들고 CPU에서 작은 학습·시험 검사를 실행합니다. 실제 제품의 성능을 확인하는 과정은 아닙니다.
- **내 사진으로 만들기**: 새 프로젝트를 만들고 필요한 결과를 고릅니다.
- **만들어 둔 작업 이어가기**: 최근 프로젝트를 엽니다. 작업 기록을 여는 것만으로 학습을 다시 실행하지 않습니다.

| 원하는 결과 | 준비할 정답 |
| --- | --- |
| 사진의 종류를 구분하기 | 각 사진의 종류를 폴더 이름으로 구분 |
| 위치와 개수 찾기 | 대상마다 사각형과 종류 표시 |
| 정확한 모양 표시하기 | 대상의 경계를 따라 영역 표시 |
| 정상과 다른 부분 찾기 | 정상 사진을 중심으로 준비하고 시험 사진의 정상·이상 여부 확인 |

아직 모르겠으면 **아직 모르겠어요**를 선택해 설명을 보고 원하는 결과를 고릅니다. 사진을 가져오는 것만으로 정답이나 작업 유형을 자동 확정하지 않습니다.

원하는 결과 아래에 **준비할 것**이 표시됩니다. 이름과 목적을 고르면 기본 위치에 프로젝트를 만들 수 있습니다. 설명이나 저장 폴더를 바꾸려면 **설명·저장 위치**를 펼칩니다. 접어도 적은 내용은 유지됩니다. 저장 오류가 나면 오류 안내와 입력값을 확인하고, 연결 문제를 해결한 뒤 **프로젝트 만들기**를 다시 누릅니다.

## 모델 종류에 맞게 준비하기

분류만 사용할 필요는 없습니다. 패치 분류·문자 인식·회전 객체 검출·이미지 개선·정방향 보정·결함 이미지 생성도 목적에 맞게 고릅니다. [전체 10종 모델 안내](pilot-model-matrix.md)에서 필요한 정답과 실행 제한을 확인합니다. 모델을 고르는 것만으로 학습이 시작되지는 않습니다.

사진을 가져온 것과 학습할 정답을 준비한 것은 다릅니다. 검출·영역 분할 사진에 라벨이 없다면 다시 가져오기보다 **라벨 달기**에서 정답을 준비합니다. 선택한 모델의 준비물·장치·누락된 실행 환경을 확인하고 시작합니다. 고정 입력 규칙 편집은 현재 분류·영역 분할에만 적용됩니다.

결함 생성 모델은 검사기가 아닙니다. 만든 후보는 사람이 검토한 뒤 학습 자료에만 채택하며 검증·시험 정답으로 쓰지 않습니다. 이상탐지의 합성 결함 점수 맵도 실제 픽셀 정답을 뜻하지 않습니다. 각 모델의 실행 완료와 현장 품질 승인은 별도입니다.

처음 사용하는 사람과 시험할 때는 [3–5명 파일럿 진행 방법](pilot-playbook.md)과 [빈 관찰 기록](pilot-session-template.md)을 사용합니다. 현재 문서는 실제 사용자 시험이 끝났다는 근거가 아닙니다.

## 네 가지 목표

1. **사진 준비**: 사용할 사진을 가져오고 종류와 수를 확인합니다. 학습에 쓸 사진과 나중에 확인할 사진을 나눠 저장합니다. 이미 나눈 시험 사진은 성능을 좋게 보이게 하려고 바꾸지 않습니다.
2. **AI 만들기**: **라벨 달기**에서 필요한 정답을 준비하고 **모델 학습**으로 이동합니다. 화면 맨 위에 먼저 필요한 입력과 복구 버튼이 나옵니다. 모델 파일·실행 환경은 **사진·모델·실행 준비 자세히**에서 볼 수 있습니다. 자르기·밝기 등은 **사진 변환 설정 (선택)**을 펼쳐 조정합니다. 학습 시간 선택은 정확도 보장이 아니며 같은 시험 사진으로 결과를 비교해야 합니다.
3. **결과 확인**: 학습에 쓰지 않은 사진에서 맞힌 것과 놓친 불량을 확인합니다. 결과가 좋지 않으면 틀린 사진의 정답과 사진 구성을 살펴보고 다시 학습합니다. 적은 시험 사진에서 나온 수치만으로 현장 성능을 확정하지 않습니다.
4. **검사 사용**: 모델과 판정 기준을 연결한 검사 흐름을 저장하고 시험 이미지로 확인한 뒤 검사를 실행합니다. 첫 시험 실행과 실제 현장의 품질 승인·배포는 별도입니다.

상단 목표와 오른쪽의 **화면 열기** 버튼은 해당 화면으로 이동합니다. 실제 실행은 **학습 시작** 같은 실행 버튼 또는 아래 자동 진행 시작에서 이루어집니다.

상단 첫 줄은 프로젝트와 메뉴, 다음 줄은 네 가지 목표와 현재 목표의 세부 작업입니다. 오른쪽에는 현재 작업과 다음에 할 일이 표시됩니다. 좁은 창에서는 이 영역이 아래로 이동합니다. 준비가 부족할 때도 강조된 버튼으로 해당 화면을 열 수 있습니다. **왜 그런가요?**에서 자세한 조건을 확인합니다.

## 여러 작업을 이어서 맡기기

사진과 라벨이 준비되면 오른쪽 **자동 진행 설정 열기**를 누릅니다. 열리는 창에서 사용할 설정을 확인하고 **자동 진행 시작**을 누르면 기존 실행기가 필요한 분할·학습·평가·검사 흐름·시험 검사 작업을 이어갑니다. 현재 입력에 맞는 완료 결과는 재사용합니다.

실행 중에는 오른쪽 **자동 진행 상태 보기**에서 실제 진행 기록과 중지 버튼을 확인할 수 있습니다. 도우미가 수행한 작업은 도우미의 작업 기록에서 확인합니다.

가져온 사진과 현재 작업이 모두 없으면 이 영역은 생략하고 각 단계의 시작 안내를 보여줍니다. 이미 실행 중인 작업은 사진을 다시 불러오는 동안에도 진행 기록을 확인할 수 있습니다.

| 화면 상태 | 할 일 |
| --- | --- |
| 진행 중이에요 | 완료 기록을 기다립니다. 같은 작업을 다시 시작할 필요가 없습니다. |
| 입력이 필요해요 | 안내된 사진·라벨·설정을 준비하고 기록에서 이어갑니다. |
| 사용 가능한 장치를 기다려요 | 연결과 실행 중인 작업을 확인합니다. |
| 자동 진행을 쉬고 있어요 | 직접 일시정지한 상태입니다. 진행 내역에서 이어갈 수 있습니다. 이미 시작한 학습의 취소는 학습 화면에서 별도로 처리합니다. |
| 실행 결과 확인이 필요해요 | 응답이 끊긴 작업은 재실행하기 전에 저장 결과를 확인합니다. |
| 작업 상태를 확인해 주세요 | 오류 기록과 해당 화면의 복구 행동을 확인합니다. |
| 작업 오류 / 학습 결과 확인 | 실패하거나 멈춘 작업의 기록을 확인합니다. 입력 부족과 구분하며 자동 재실행하지 않습니다. |
| 요청한 실행이 끝났어요 | 저장된 결과를 살펴봅니다. 현장 품질 승인 완료를 뜻하지 않습니다. |

## 검증 범위

이번 변경은 처음 시작 동선과 상태·복구 안내의 개선입니다. 전문 라벨러 엔진 교체나 모델 성능 개선을 포함하지 않습니다. 화면·자동 검사 통과와 AI를 처음 쓰는 실제 사용자의 완주율은 별도 근거가 필요합니다.


## 필요한 도구 찾기

- **사진 준비**: 사진을 중심으로 확인합니다. 비율·클래스 통계는 **분할·클래스·데이터 관리 도구**, 서버 경로 입력은 **폴더 경로로 가져오기**를 펼칩니다.
- **AI 만들기**: 라벨 달기와 모델 학습을 오갑니다. 실행 중인 상태와 연결 복구는 접힌 설정 밖에 표시됩니다.
- **결과 확인**: 놓친 불량과 과검 사진부터 살펴보고 비교·지표·이력은 필요한 항목을 펼칩니다.
- **검사 사용**: 저장한 흐름과 입력을 확인합니다. 모델 내보내기·배포 도구는 추가 도구에서 엽니다. 검사를 실행한 것만으로 현장 승인이 완료되지는 않습니다.
- 용어가 어렵다면 상단 **설정·도구 → 용어 사전**을 엽니다.
