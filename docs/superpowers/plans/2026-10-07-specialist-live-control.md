# Specialist live control continuation

Continue S1-08 in the isolated Codex checkout. Existing user authorization covers implementation and owned synthetic CPU verification.

## Design

Specialist jobs run inside a shared backend process. Process liveness alone cannot prove that a particular training closure remains active. Current opted-in POSIX admissions will expose a private, bounded, read-only Unix-domain challenge endpoint during their execution scope. The OS peer PID, exact backend PID/create time/command, immutable job/spec/namespace/output/lease/fence acknowledgment and live original thread must all agree before migration. Unsupported platforms and old workers remain drained-only.

Only short control operations share installation maintenance admission. Model outputs stay in the original registered project. The existing sealed generation carries the exact original specialist admission and reservation; it grants no launch/replay/re-fencing ability. Uncertain reservations stay uncertain. Completion and cancellation follow the same job and fence in the new ledger. A later attempt fences the original adapter out.
