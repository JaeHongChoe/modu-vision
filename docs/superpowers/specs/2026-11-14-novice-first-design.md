# 모두비전: 처음 만드는 검사 AI

## 승인된 방향
2026-11-14 서비스/초보자 사용성 검토 후 사용자가 구현을 요청했다. 기존 제조 검사 워크벤치의 시각 체계와 실행 계약을 보존하면서, AI를 모르는 사람이 자기 사진으로 첫 학습과 시험 검사를 완료하는 길을 만든다.

## 사용자 경험
- 시작 안내는 예제로 해보기 / 내 사진으로 만들기 / 만들어 둔 작업 이어가기 세 가지 실제 진입점을 제공한다.
- 새 프로젝트에서는 분류·객체 검출 같은 기술 이름보다 원하는 결과(사진의 종류, 위치와 개수, 정확한 모양, 정상과 다른 부분)를 선택한다. 각 선택은 기존 task 값에 명시적으로 대응한다. 모르겠어요는 설명을 제공하고 자동으로 정답이나 검사 유형을 추정하지 않는다.
- 간단히 보기는 사진 준비 → AI에게 가르치기 → 처음 보는 사진으로 확인 → 검사에 사용의 네 목표로 안내한다. 내부 1~6단계와 전문 기능은 유지한다.
- 현재 작업/다음 행동은 기존 준비도와 실제 작업 기록을 사용한다. 단순 화면 이동 버튼은 실행이라고 표현하지 않는다.
- 기존 원클릭 실행기를 통해 저장된 분할/학습/평가/흐름/시험 검사 결과를 재사용한다. 새 스케줄러를 만들거나 프로젝트·권한·정답·동시 실행 가드를 약화하지 않는다.
- 학습 준비는 필요한 입력과 바로 고치는 행동이 먼저, 모델/장치/환경 세부 정보는 자세히에서 제공한다. 오래 학습하면 정확해진다거나 일정 장수면 믿을 수 있다는 보장은 제거한다.
- 예제/첫 시험 완료와 현장 품질 승인/배포는 구분한다. GPT 연결 없이도 기본 경로가 동작한다.

## 범위와 보존
라벨러 엔진 전체 교체, 모델 품질 향상, 운영 배포와 계정 변경은 이번 변경에 포함하지 않는다. 원본 이미지, 확정 라벨, 고정 시험 세트, 모델, 저장 버전, 기존 프로젝트와 실행 중 작업을 보존한다. 로컬 UI/합성 검증은 실제 사용자 성공률 또는 현장 품질 검증으로 확대하지 않는다.

## 검증
목적→task 매핑/미선택 거절, 시작 안내의 실제 진입점, 네 목표 탐색과 내부 단계 매핑, 진행/차단/복구 및 프로젝트 전환, 준비도 가드 보존을 의미 있는 컴포넌트/순수 함수 테스트로 검증한다. 타입 검사와 renderer suite를 실행하고 격리된 화면으로 시각 검토한다. 실제 사용 앱/웹 교체는 별도 릴리스 단계다.
