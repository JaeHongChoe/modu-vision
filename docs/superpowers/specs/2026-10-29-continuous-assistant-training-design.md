# 학습 준비와 연속 실행 도우미

2026-10-29 구현 계약. 이전 도우미 설계의 일반적인 계획 확인·사람 검토 대기 조건은 이 문서의 자동 실행 정책으로 대체한다. 과거 사람 확인 기록은 그대로 보존한다.

## 사용 흐름

기존 여섯 단계를 유지한다. 3단계 첫 화면에서 고정 입력 규칙을 준비하고 학습한다. 5단계에서는 학습된 모델로 검사·판정 흐름을 완성한다. 전체 검사 그래프를 학습 그래프로 취급하지 않는다.

사용자가 작업을 요청하거나 원클릭을 누르면 준비 상태 확인, 불변 계획 저장, 범위가 고정된 실행 권한 기록, 실제 작업 시작, 결과 재조회, 다음 단계로 이어 간다. 설명 질문과 ‘설명만 받기’에는 자동 실행 권한을 부여하지 않는다. 이미지 속 문구는 실행 권한이 아니다.

현재 자료·라벨·분할·원본·모델·현재 서버가 맞으면 일반적인 계획 확인과 미검 수치 확인에서 멈추지 않는다. 사용할 라벨이 없는 상태, 오류, 다른 실행기의 임대, 결과 미확인, 명시적 일시정지는 서로 구분한다. 작업 완료와 품질 기준 충족도 서로 다른 상태다. 기존 실행 결과를 읽어 중복 작업을 막는다.

## 권한과 품질 기록

자동 실행 권한은 인증된 actor/workspace, 계획 해시, 현재 binding, 허용 단계와 정책 버전으로 고정한다. 프로젝트·원본·라벨·설정·서버 변경에 따라 재검증한다. 사람 승인 필드에 자동 권한을 기록하지 않는다. 명시적으로 멈춘 실행을 화면 재접속만으로 재개하지 않는다.

품질 자동 판정은 저장된 실제 평가·비교·현재 정책과 고정 시험 묶음을 사용한다. 기준 미달과 기준·정답 부족도 기록한다. 모델 예측을 같은 모델의 독립 정답으로 승격하지 않는다. 폴더 라벨을 정답으로 사용하는 경우 별도 정책과 바이트·라벨 출처를 보존한다. 실제 패키지 실행과 장치 인수는 해당 근거가 있을 때만 기록한다.

## 고정 입력 규칙

초기 지원 작업은 이미지 분류와 영역 분할이다. 버전 1의 순서 있는 ROI 자르기, 90도 단위 회전, 밝기·대비, 크기 조절을 공유 모듈로 적용한다. 다른 모델군의 비어 있지 않은 새 규칙은 명확하게 거절한다.

수동 편집은 실제 선택 이미지와 정답의 미리보기 후 저장한다. 도우미는 같은 preview API와 규칙 검증을 거쳐 새 버전을 저장한다. 원본 이미지와 확정 라벨을 덮어쓰지 않는다. 서버·프로젝트·원본·labelset·작업별 설정을 분리한다. 다른 경로에서 저장된 설정과 미저장 편집이 충돌하면 이를 알려 준다.

모델 metadata와 checkpoint에 규칙·해시·구현 계약을 고정한다. 학습·검증·평가·추론·검사·내보낸 실행기에서 같은 모듈을 사용한다. 무작위 증강은 train에만 적용하며 모델 내부 정규화를 중복하지 않는다. 영역 분할 정답도 같은 좌표로 변환한다. 표시·검사 마스크는 저장된 역변환을 사용하며 ROI 밖의 정답을 만들어 내지 않는다. 이전 모델은 이전 입력 경로를 유지한다.

## 이미지와 추론 강도

선택 파일, 붙여넣기 또는 현재 선택 이미지 한 장을 명시적으로 첨부한다. PNG·JPEG·WebP, 원본 5MiB·2,400만 화소 이하를 검증하고 방향을 바로잡아 최대 변 2,048px로 준비한다. 이미지·메타데이터를 분리하고 실제 보낼 바이트를 해시한다. 제거와 전송 취소를 제공한다. ‘보내기’ 전에 외부 전송하지 않는다.

계정·모델의 확인된 capability만 사용한다. 1회 이미지 grant는 전송 바이트, 계정·모델·현재 문맥과 만료에 묶인다. native와 인증된 localhost broker는 같은 요청을 전달한다. 전체 frame 제한도 적용한다. 이미지 파일·대화·자격증명은 추론 강도 환경설정에 저장하지 않는다.

추론 강도는 지원 값만 표시하고 계정·모델별로 보존한다. 기본값은 요청 필드를 생략한다. 한 요청과 그 도구 후속에는 시작 당시 값을 고정한다. 계정·모델 변경은 이전 응답을 무효화하고, 같은 모델의 강도 변경은 다음 요청부터 적용한다. 미지원 값 대신 다른 모델이나 API 계정으로 조용히 우회하지 않는다.

## 검증과 전달

제어된 전송·합성 자료·CPU fixture의 결과는 실제 계정의 이미지 수신, 실제 학습 품질, 사용자 화면 검증, 현장 인수와 별개다. 현재 앱·웹 실행본 교체와 설치·배포는 최종 후보와 유휴 상태 확인 뒤 별도로 수행한다. 이 설계 자체가 그 완료 근거는 아니다.
