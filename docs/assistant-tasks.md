# 말로 작업을 맡기는 도우미

앱이나 이 컴퓨터의 localhost 웹에서 도우미를 열어 작업을 맡길 수 있습니다. 하단의 **왜 그런가요? → 도우미에게 묻기**로 열고, 처음에는 ChatGPT 연결과 모델 선택을 직접 완료하세요.

1. 원하는 일을 적습니다. 예: “이 자료를 학습70%, 검증20%, 시험10%로 나누고 빠른 학습을 준비해줘.”
2. 도우미가 제안한 **작업 계획과 입력값**을 읽고 **계획 확인하고 실행**을 누릅니다. 폴더 선택 창이 뜨면 사용할 폴더를 직접 고릅니다.
3. 카드에서 현재 단계와 저장 결과를 확인합니다. **작업 일시정지**는 다음 도우미 작업을 멈춥니다. 이미 시작한 학습은 계속되며, 학습을 중단하려면3단계의 중단 기능을 사용합니다.
4. 멈춘 이유에 맞는 버튼을 사용합니다. 폴더 선택을 취소했다면 **폴더 선택하고 이어하기**, 라벨 초안 검토라면 **검토 화면 열기**, 정답 확인이라면 **정답 확인 화면 열기**가 표시됩니다. 검토를 마친 뒤 **검토 결과 확인하고 이어하기**를 누릅니다. 라벨 채택·정답 확정·최종 모델/흐름 승인과 배포는 직접 합니다.

![합성 자료와 제어된 응답으로 검증한 작업 계획 예시](verification/assets/task-assistant/plan-390-dark.png)

새로고침 뒤에는 로그인과 기존 ChatGPT 계정·모델 선택을 다시 확인하세요. 도우미는 저장된 작업을 읽으며 완료한 작업을 자동으로 다시 실행하지 않습니다. 학습의 임시 장치·배치 입력만 초기화됐다면 **저장 설정 복원**이 표시됩니다. 이 버튼은 표시된 입력만 복원하고 학습을 시작하지 않습니다. 이어가기는 그 다음에 별도로 확인합니다.

프로젝트·원본 자료·실행 서버·계정이 달라졌거나 직접 다른 설정을 입력했다면 저장 설정을 덮어쓰지 않습니다. 원래 작업을 다시 열어 확인하거나 현재 상태에 맞는 새 계획을 요청하세요. 응답이 끊겼다면 카드의 안내에 따라 저장 결과를 확인하세요. **저장 결과 확인하고 계획 계속**과 **저장 결과 확인하고 이어하기**는 결과를 확인한 뒤 승인한 나머지 작업을 이어가는 버튼입니다. 오류만 보고 학습이나 평가를 다시 시작하지 마세요.

## 이전 계획 대신 다른 일을 맡기려면

**이 계획 멈추고 새 요청**을 누르세요. 이어갈 수 있는 이전 계획은 일시정지하고 기록으로 남깁니다. 작성 중이던 질문은 입력창에 그대로 남으며, 버튼만 눌러서는 질문을 보내거나 새 작업을 실행하지 않습니다. 원하는 질문을 보낸 뒤 새 계획을 확인하세요.

이미 실행 중이거나 결과가 아직 확인되지 않은 작업이 있으면 그 이유를 표시합니다. 이 경우 기존 작업의 결과를 먼저 확인해야 새 실행 계획을 만들 수 있습니다. 상태나 오류에 관한 질문은 계속 입력할 수 있습니다. 시작한 학습·평가를 새 요청 버튼으로 취소하지 않습니다.

**대화만 비우기**는 채팅만 지웁니다. 저장된 계획은 유지됩니다. **계획 기록 새로 보기**에서 이전 계획을 골라 확인할 수 있으며, 기록을 여는 것만으로 작업이 실행되지는 않습니다.

상태 조회가 오래 걸리면 **상태 확인 대기 중지**로 기다리기를 끝낼 수 있습니다. 조회가15초 안에 끝나지 않아도 입력창을 다시 사용할 수 있게 안내합니다. 이 동작은 이미 승인해 실행 중인 작업을 중단하거나 재시도하지 않습니다.

도우미는 프로젝트 준비, 자료 가져오기·분할, 지원되는 라벨 초안과 학습, 모델·저장 흐름 평가, 시험 검사, 보고서 저장, 화면 이동을 수행합니다. 필요한 자료·모델이 없거나 지원하지 않는 작업이면 이유와 확인할 화면을 보여 줍니다. 사용자가 검토하기 전 초안은 정답이 아닙니다.

현재 새 작업 실행은 macOS/Linux에서 지원합니다. Windows 작업 실행은 준비 중입니다. localhost 웹에서는 기존 네이티브 기능 사용 허용과 폴더 선택이 필요할 수 있습니다. ChatGPT에는 텍스트와 구조화된 앱 상태만 제공하며 원본 이미지·화면 캡처는 전송하지 않습니다.

“지금 왜 막혔어?”, “이 오류 확인해줘”라고 물으면 도우미가 현재 상태와 등록된 오류, 최근 요청 실패, 저장된 작업 결과를 읽을 수 있습니다. 학습·평가·검사 흐름·계산 위치의 세부 상태도 조회합니다. 오류 코드와 HTTP 상태, 기존 작업 번호, 저장된 결과를 함께 확인하므로 응답이 끊겼다는 이유만으로 같은 작업을 다시 시작하지 않습니다.

현재 화면의 오류와 과거 요청 실패는 구분합니다. 출처가 확인되지 않은 오류는 범위 미확인으로, 읽지 못한 상태는 미확인으로 표시합니다. 진단은 앱에 등록된 상태·오류와 현재 계정/프로젝트의 작업 조회를 대상으로 하며 전체 서버 로그를 자동 수집하지 않습니다. 최근 요청 실패는 메모리에 최대40건만 보관하고 새 계정·프로젝트·연결 문맥에서는 이전 이력을 제공하지 않습니다.

오류나 작업이 많으면 목록을 나눠 읽습니다. 생략된 항목 수와 다음 위치를 제공하므로 첫 화면에 없는 이력도 범위 안에서 확인할 수 있습니다.

진단 읽기와 계획 기록 조회는 학습·평가·재시도를 시작하지 않습니다. **계획 계속**이나 **이어하기**를 선택하면 이미 승인한 계획의 남은 작업을 실행할 수 있습니다. 작업 폴링·복원·완료 이벤트는 GPT를 자동 호출하지 않습니다. 다음 질문에서 최신 요약을 전달하고 필요한 상세 정보를 다시 읽습니다. 작업 내용을 바꾸려면 새 계획을 제시하며, 그 계획을 확인한 뒤 실행합니다. 결과가 불명확하거나 진행 중인 작업은 먼저 기존 기록을 확인해야 합니다.
