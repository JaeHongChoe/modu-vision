# 말로 작업을 맡기는 도우미

앱과 이 컴퓨터의 localhost 웹에서 도우미를 열어 작업을 맡길 수 있습니다. 처음 한 번 ChatGPT 계정 연결과 사용할 모델을 선택합니다. 도우미 없이도 모든 단계를 사용할 수 있습니다.

## 준비된 작업은 이어서 실행

“이 자료로 학습하고 평가까지 해줘”, “검사 흐름을 만들고 시험 이미지를 검사해줘”처럼 요청합니다. 도우미는 현재 프로젝트와 지원 기능을 읽고, 사용할 데이터·라벨·설정이 준비돼 있으면 계획을 저장한 뒤 이어서 실행합니다. 일반적인 계획 확인이나 미검 수치 확인 때문에 매번 사람 검토를 기다리지 않습니다. 원클릭도 같은 작업 실행기와 저장 기록을 사용하며 GPT 연결 없이 실행할 수 있습니다.

설명이나 상태 질문은 작업 실행과 구분합니다. **설명만 받기**를 선택하면 질문에 작업 표현이 있어도 자동 실행 권한을 주지 않습니다. 수동으로 준비한 계획이나 예전 계획에는 확인·이어가기 버튼이 남을 수 있습니다.

| 상태 | 표시와 동작 |
| --- | --- |
| 작업 진행 중 | 실제 작업과 저장된 결과를 확인하고 다음 단계로 진행 |
| 학습·평가를 기다림 | 기존 작업 번호를 조회. 기다림은 사람 검토나 완료를 뜻하지 않음 |
| 자료·라벨 부족 | 필요한 자료와 해당 화면을 안내. 유효한 라벨이 있으면 남은 초안만으로 막지 않음 |
| 정답 또는 정책 기준 부족 | 가능한 추론과 결과는 보존하되 정확도·품질 판정을 통과로 만들지 않음 |
| 실행 오류 | 오류와 기존 작업 결과를 확인. 응답이 끊겼다는 이유로 중복 실행하지 않음 |
| 일시정지 | 이후 단계를 멈춤. 명시적으로 멈춘 작업을 스스로 재개하지 않음 |

**작업 일시정지**는 다음 도우미 작업을 멈춥니다. 이미 시작된 학습은 독립적으로 계속될 수 있으며, 학습 자체를 취소하려면 3단계의 중단 기능을 사용합니다. **대화만 비우기**와 **계획 기록 새로 보기**는 저장된 작업을 실행하거나 삭제하지 않습니다. 실행 중이거나 결과가 불명확한 작업은 실제 저장 상태를 확인한 뒤 다음 요청을 처리합니다.

자동 실행 권한과 품질 정책에 따른 판단은 사람 검토와 다른 기록입니다. 사람 이름·정답 확인·품질 승인을 임의로 작성하지 않습니다. 기존 폴더 라벨로 시험 정답을 구성하는 경우에도 원본·라벨·정책 출처를 별도로 기록합니다. 모델의 예측을 그 모델 자신의 독립 평가 정답으로 쓰지 않습니다. 별도 초안은 확정 라벨을 덮지 않습니다.

## 이미지와 함께 질문하기

이미지 입력을 지원하는 모델에서 **이미지 첨부**, **현재 이미지 첨부** 또는 붙여넣기를 사용합니다. PNG·JPEG·WebP 한 장, 원본 5MB·2,400만 화소 이하를 지원합니다. 방향을 바로잡고 긴 변이 최대 2,048px인 첨부를 준비하며 파일 메타데이터를 제외합니다. 첨부 미리보기에서 확인하거나 해제할 수 있습니다. **보내기**를 누르면 선택 이미지와 질문이 표시된 ChatGPT 모델로 전송됩니다. 같은 질문의 도구 후속에도 동일 첨부를 사용하며, 각 전송은 현재 문맥을 다시 확인합니다. 다음 질문에 이미지를 자동 재첨부하지 않습니다. 전체 폴더나 다른 프로젝트 이미지를 자동으로 전송하지 않습니다.

“이 이미지로 학습 준비해줘”처럼 맡긴 작업은 현재 프로젝트의 실행기로 연결됩니다. 이미지 속 문구 자체가 실행 권한을 만들지는 않습니다. 이미지 입력을 지원하지 않거나 지원 정보가 확인되지 않은 모델에는 이미지를 보내지 않습니다. 계정·프로젝트·모델·이미지 문맥이 바뀌면 오래된 첨부와 늦은 응답을 사용하지 않습니다.

## 추론 강도

연결 설정의 **추론 강도**에서 해당 모델의 지원 값만 선택합니다. **모델 기본값**은 공급자의 기본 동작을 사용합니다. 설정은 계정·모델별로 보존하며 실제 요청에 전달합니다. 같은 계정·모델에서 강도만 바꾸면 진행 중 요청은 시작 당시 값으로 끝내고 다음 요청부터 새 값을 사용합니다.

강도가 높으면 응답 시간과 사용량이 늘어날 수 있습니다. 검사 판정 기준 점수, 학습 옵션, 이미지 크기와는 별개입니다. 지원 정보가 없는 모델은 기본값으로 요청하며 다른 모델이나 API 키 방식으로 조용히 바꾸지 않습니다.

## 연결·작업 복구

새로고침 후 저장된 작업과 실제 작업 번호를 다시 읽습니다. 상태 조회가 오래 걸리면 **상태 확인 대기 중지**로 화면의 기다림을 끝낼 수 있습니다. 이 동작은 학습·평가를 취소하거나 재실행하지 않습니다. 프로젝트·계정·원본·라벨 버전이 바뀌었으면 이전 쓰기 권한을 재사용하지 않습니다.

도우미는 앱이 제공하는 현재 상태·오류·최근 요청 실패·저장 결과를 읽습니다. 일부 조회를 전체 서버 로그 조사로 표현하지 않으며, 현재 오류와 과거 실패, 생략되거나 읽지 못한 상태를 구분합니다. 작업 폴링과 복구는 GPT를 자동 호출하지 않습니다.

현재 새 작업 실행은 macOS/Linux 경로이며 Windows는 준비 중입니다. localhost 웹의 계정 로그인, 컴퓨터의 네이티브 기능 허용과 ChatGPT 계정 연결은 별개입니다. 지정되지 않은 운영 서버 배포나 새 권한은 일반 작업의 자동 진행 범위에 포함되지 않습니다.
