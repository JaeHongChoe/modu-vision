# 5단계 검사 흐름 준비

간단히 보기에서는 학습한 모델로 실제 검사 순서를 준비합니다. 이미 만든 흐름은 그대로 유지합니다.

1. **사용할 모델**에서 연결된 모델과 검사 종류를 확인합니다. 모델을 바꾸려면 `모델 다시 선택`으로 4단계에 갑니다. 모델이 연결되지 않았다면 `기본 검사 흐름 구성`으로 미리보기를 열 수 있습니다. 기존 흐름은 미리보기를 확인하고 채택해야 바뀝니다.
2. **판정 기준**에서 어떤 결과를 정상·불량으로 볼지 확인합니다. 점수 판정은 기준 점수와 단위, 개수 판정은 허용 개수를 표시합니다. 복잡한 패치·분기 규칙은 `판정 기준 수정`에서 확인합니다.
3. **흐름 저장**에서 모델·판정 기준을 저장합니다. 기존 저장 확인창과 변경 사유 절차를 사용합니다. 화면을 옮기는 것만으로 저장되지 않습니다.
4. **시험 이미지 확인**에서 저장한 전체 흐름을 확인합니다. 4단계는 모델 성능을 평가하고, 여기서는 전처리·모델·판정 규칙을 함께 적용합니다. 시험 이미지와 정답 준비가 필요하면 화면에 다음 작업이 표시됩니다. 정답 확정은 사람이 직접 검토합니다.
5. 현재 저장 버전과 일치하는 유효한 평가 근거를 확인한 뒤 **6단계 검사 실행**으로 이동합니다. 최종 승인·내보내기·배포 조건은 6단계에서 별도로 확인합니다.

화면 아래의 주요 버튼은 현재 필요한 작업 하나를 안내합니다. 저장하거나 규칙을 바꾸면 이전 평가가 현재 근거로 인정되지 않을 수 있습니다. 이미 한 단일 이미지 검사는 전체 흐름 평가를 대신하지 않습니다.

## 고급 편집

`고급 편집`에서 노드 연결, 여러 모델, ROI, 분기, 세부 판정 규칙, 저장 버전·이력과 기존 시험 도구를 사용합니다. `검사 준비로 돌아가기`를 눌러도 노드·연결·미저장 수정은 유지됩니다. `모두 보기`에서는 기존 편집기를 계속 사용합니다.

이미 실행 중인 검사가 있으면 `진행 중 검사 상태 확인`으로 상태·복구 제어를 엽니다. 상태를 보는 것만으로 검사를 중단하거나 다시 시작하지 않습니다.

GPT 작업 도우미도 같은 저장·평가 기능을 사용합니다. 계획 실행 완료와 사람이 판단하는 모델 품질·정답·운영 승인은 별개입니다.
