# 저장 브러시 마스크의 실제 클래스 집계

브러시 주석에는 사각형·다각형 좌표가 없어서 가져오기 통계에서 빠지고,
`defect`로 대체되거나 다른 도형 옆에서 누락되던 문제를 수정했습니다.

- 활성 라벨 세트의 실제 저장 마스크에서 쓰인 양수 ID의 이름만 셉니다.
  한 이미지의 같은 클래스는 여러 획·도형이 있어도 한 번만 셉니다.
- 가져오기·현재 요약·통계가 같은 읽기 전용 함수를 사용합니다. 빈 래스터는
  전경 클래스가 없고, 팔레트에만 있는 클래스는 집계하지 않되 원본 팔레트는 보존합니다.
- 배경 0, 명시적 클래스 255, 이름 없는 이진 마스크 변환, 명시적 태그,
  클래스 이름 충돌·라벨 세트·스키마·I/O 보호를 유지합니다.
- 객체 검출의 객체 수, 분류·원본 폴더 마스크 규칙과 학습 라벨 읽기는 바꾸지 않습니다.

## 확인한 근거

- 수정 전 유효한 실제 API fixture에서 5개 집계 단언이 실패했습니다.
  브러시 Scratch, 도형/브러시 혼합, 빈 마스크, 팔레트만 남은 주석과 활성 라벨 세트입니다.
  통계의 래스터 경계 시험 10개와 별도 브라우저 집계 시험도 먼저 실패했습니다.
- 관련 백엔드 **113/113** 통과. 원본·주석·래스터·팔레트뿐 아니라 프로젝트·라벨 세트·
  검수 workflow JSON까지 의도한 fixture 준비가 끝난 후 해시로 보존을 확인했습니다.
- 브라우저 **2/2** 통과: 기존 브러시/지우개/실행 취소/재실행/재열기와 새 독립 집계 시험.
  합성 PNG를 저장한 뒤 실제 화면 클래스 칩과 import/current-summary/statistics/reopen을 확인했습니다.
- E2E 타입과 source/action 근거 게이트 통과. 과거 실행 당시의 시험 바이트는 보존된
  조상 커밋과 원본 영수증으로 유지합니다. 현재 시험 파일 8개의 데이터 라우트 소스 핀과
  기존 과거 선언 17개의 현재 파일 해시·설명을 갱신하며, 원본 실행 영수증이나 수락 상태를
  다시 쓰지 않습니다. 이 과거 선언 갱신은 새 GUI 실행이나 현재·네이티브·사람 수락의 근거가 아닙니다.
- 독립 작업 검토와 최종 전체 변경 검토에서 차단할 결함은 없었습니다. 검토자는 저장된
  검증 로그와 변경 소스를 읽었으며 시험을 별도로 재실행한 것으로 주장하지 않습니다.

## 환경과 남은 검증 경계

기존 로컬 FastAPI 0.108 환경에서는 원래 코드도 원본 요약 검사 2개가 APIRouter.app
호환성 오류로 실패했습니다. 별도 환경에 저장소 잠금 파일의 해시로 확인한 FastAPI 0.142.2,
Starlette 1.7.0과 필수 보조 패키지만 설치해 확인했습니다. 다른 ML 패키지는 기존 환경을
상속하므로 전체 CI 잠금 환경이라고 부르지 않습니다.

그 환경의 관련 시험은 **114 통과·1 기존 실패**입니다.
`test_original_current_summary_saved_metadata_reads_close_and_drain`의 정확한 응답 기대값이
기존 필드 4개를 빠뜨립니다. 수정 전 코드에서도 같은 4개 필드 차이로 실패했고,
클래스 수 차이는 없습니다. 외부 선택자 거절 시험은 통과했습니다. 이 기대값이나 제품을
우회 수정하지 않았으며 전체 백엔드 성공을 주장하지 않습니다.

사용자의 원본과 실제 계정·모델을 사용하지 않은 통제된 검증입니다. 현장 품질과 사람 수락은
별도이며, 정확한 공개 head의 원격 CI·검토 결과는 해당 PR에 기록합니다.
