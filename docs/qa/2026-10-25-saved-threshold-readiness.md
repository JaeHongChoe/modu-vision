# 저장된 평가 기준과 미리보기 분리

화면에서 시험용 판정 점수를 바꾸는 것만으로 4단계 준비 판단과 자동 진행의
미검 정지가 풀리던 경로를 수정했습니다. 예를 들어 저장 기준 .50에서 점수 .30인
불량은 미검입니다. 미리보기만 .20으로 내려도 저장된 결과의 미검은 그대로입니다.

- 평가 저장소가 저장된 기준과 미리보기 기준을 따로 관리합니다. 저장 성공을
  확인한 보정만 새 기준이 되며, 실패·대기·늦은 응답은 이전 기준을 유지합니다.
- 기존 저장 보정 형식, 기준값 0과 거리 점수를 지원합니다. 알 수 없는 기준은
  준비 완료로 간주하지 않습니다. 추천 분석은 저장된 판정 근거를 바꾸지 않습니다.
- 하단의 '틀린 이미지 보기'는 저장된 미검 목록을 엽니다. 목록·선택 판정·뷰포트·
  히트맵이 같은 기준을 사용하고, 같은 버튼으로 미리보기로 돌아올 수 있습니다.
  미리보기 탭·점수·행렬 조작도 기존 동작으로 돌아갑니다. 저장 자체는 하지 않습니다.
- 기준·이미지·평가 소유권이 바뀌면 이전 히트맵과 진행 중 요청을 즉시 무효화합니다.
  새 요청이 실패하면 이전 픽셀을 보여주지 않고 저장 기준의 히트맵을 확인할 수 없다고 알립니다.
- 원본·라벨·라벨 세트·평가 파일·수동 단계 이동과 기존 보정 API는 변경하지 않습니다.

## 확인한 근거

- 수정 전 실제 저장소·준비도 hook·판정 함수의 재현 시험이 실패했습니다.
  강화한 첫 재현 묶음은 119개 중 36개가 예상대로 실패했습니다.
- 독립 검토가 찾은 '저장된 미검 안내가 미리보기의 빈 목록을 여는 문제'도 실제
  목적지 클릭으로 먼저 재현했습니다. 이미 선택한 미검 탭, 반복 열기, 미리보기
  복귀, 같은 이미지의 히트맵, patch-score 경계와 REVIEW를 함께 확인했습니다.
- 최종 관련 Node 통합 시험 **162/162**, 전체 renderer/main Node **2181/2181** 통과.
  renderer/main·E2E 타입, 빌드, action/service 근거 게이트와 diff 검사 통과.
- 독립 작업 검토와 최종 전체 변경 검토에서 나온 미검 보기·히트맵 문제를
  실패 재현 후 수정했고, 각각의 재검토에서 추가 차단 문제 없이 승인됐습니다.
- 실제 격리 브라우저의 저장된 분할 평가 겹침·출처 거절 회귀 **1/1** 통과.
  합성 원본과 통제된 저장 보고서를 사용한 일반 화면 회귀이며, 새 미검 클릭 경로의
  근거는 위 Node 통합 시험입니다. 실제 모델·계정 또는 현장 품질 검증은 아닙니다.
- 초기 전체 시험에서 발견한 미확인 기준의 표시 오류와 테마 생성 불일치는
  수정 후 전체 시험을 다시 통과했습니다. 실패 기록은 로컬 검증 기록에 보존했습니다.

기존 Vite 혼합 import·큰 chunk 경고와 의도된 실패 시험의 console 진단은 남습니다.
실제 사용자 측정·현장 품질·실계정 검증은 이 변경의 완료 주장에 포함하지 않습니다.
정확한 공개 head의 원격 검사와 검토 결과는 해당 PR에 별도로 기록합니다.

1 실패였습니다. 실패는 비교 작업 제출 응답의 10초 시간 초과이며 원인은 미확정입니다.
이전 실패를 새 head의 성공으로 덮거나, 이 변경이 그 원인을 고쳤다고 주장하지 않습니다.
