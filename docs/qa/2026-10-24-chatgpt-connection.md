# ChatGPT 연결 코드와 모의 검증 (2026-10-24)

앱 자체의 로컬 OAuth/계정 저장/전송/설정 화면을 연결했다. 실제 사용자 계정으로
로그인하거나 OpenAI에 등록·추론 요청을 보낸 결과는 아니다. API 키 입력·약관
수락·플랜 동의·이미지 외부 전송을 사용자 대신 수행하지 않았다.

## 구현 범위

- `siwcStore`: 별도 OS 암호화 파일, owner-only/원자 교체, 계정별 등록/모델,
  독점 잠금, 로그아웃 후 host/client 대응 보존. 일반 설정 읽기는 신규 OAuth
  파일이나 잠금을 만들지 않는다. 오래된 잠금은 자동 삭제하지 않는다.
- `siwcConnection`: 명시 버튼 이후 실제 loopback listener를 먼저 열고 시스템
  브라우저로 PKCE 시작. 공식 HTTPS origin/endpoint, 리디렉션 거절, bounded
  discovery/JWKS, 서명/issuer/aud/nonce/returning-sub 검증, identity-only scope 보존.
- 선택한 계정의 표시 가능한 모델을 읽고 사람이 모델을 고른 뒤 텍스트 요청.
  `store:false`/`stream:true`, namespace 도구와 stateless replay,
  `response.completed`만 성공. 한도/실패/불완전 SSE를 성공으로 보여주지 않는다.
- 갱신은 같은 계정에서 직렬화하고 교체 토큰 저장 뒤 사용한다. 불확실 갱신은
  재연결이 필요하다. 로그아웃은 로컬 지우기와 원격 폐기 확인을 구분한다.
- 계정/모델 변경 시 진행 요청과 확인 대기를 무효화한다. 텍스트 전용이며
  renderer·IPC·프로젝트 감사 기록으로 토큰/등록 identity를 반환하지 않는다.
- API 키 공급자는 별도 유지한다. 연결 대기 상태만 잠깐 조회하고 15분 자동화는 재개하지 않는다.

## 검사와 실제 화면 범위

- 전체 renderer/main Node 명령: **1948/1948**, 실패/skip 0.
- renderer/main 및 E2E 타입 검사, production build, API 타입 생성 일치, diff 검사 통과.
  빌드의 기존 큰 번들·정적/동적 import 경고는 남아 있다.
- 관련 backend 실행 기록 검사 **13 통과**. Starlette `python_multipart` 경고 1개.
  전체 backend 통과나 실모델 품질 승인의 근거가 아니다.
- 근거 게이트: action evidence ok/accepted features 0, service plan ok/accepted work packages 0.
- 실제 브라우저 renderer/backend UI 2건 통과: 약관 미체크 호출 0 → 연결 대기 →
  identity-only 전송 비활성 → 명시 계정/모델 선택 → 텍스트만 활성/이미지 비활성 →
  모의 한도 안내와 사용량 링크 → 로컬 로그아웃/원격 미확인 안내.
  두 번째는 초안 쓰기 거절 시 저장 0회/확인 시 분할 저장 1회와 실행 기록이다.
  main IPC 응답은 가짜 공개 상태이며 실제 계정·키·공급자 호출·이미지 전송은 없다.
- Node 연결 검사는 가짜 HTTPS/생성 토큰/실제 127.0.0.1 콜백 listener를 썼다.
  프로세스 간 저장소 경쟁, 재시작, 갱신/콜백/철회 취소, SSE 완료/실패를 확인했다.
  네이티브 OS 계정 인증이나 실제 OpenAI 토큰 수령 시험으로 확대하지 않는다.

첫 전체 Node 실행은 생성 테마의 사용 횟수 주석이 최신 소스와 달라 1947 통과/1실패였다.
생성 파일을 갱신한 뒤 1948/1948을 확인했다(실제 색 규칙 변경 없음).
첫 UI 사전 검사는 기본 `python3`에 FastAPI가 없어 멈췄고, 기존 프로젝트 `.venv`
interpreter를 명시한 뒤 2건을 실행했다. 패키지를 새로 설치하지 않았다.

## 독립 검토에서 수정한 경계

1. 종료 중 회전 갱신의 이전 토큰이 재시작 때 다시 쓰일 수 있었다. 종료 전
   해당 보관 토큰을 지우고, 지우기 실패 시 잠금을 보존하는 재현 검사로 고쳤다.
2. ChatGPT 저장소를 읽지 못할 때 API 공급자로 자동 전환될 수 있었다. 선택한
   수신처를 별도 보존하고 오류 시 전송을 거절한다. API 공급자는 명시 선택으로만
   바꾼다. 동시에 OAuth 저장소 오류가 API 전용 설정까지 막던 문제도 고쳤다.
3. 임의 replay 중첩 필드에 이미지/경로/키를 넣을 수 있었다. 입력/출력 중첩 구조를
   엄격히 검사하고 일반 텍스트를 가린다. main이 검증해 반환한 replay 지문만
   같은 계정/모델 authority에서 재사용하며 변조·이전 계정 replay를 전송 전에 거절한다.

각 재현 검사가 먼저 실패하고 수정 후 통과했으며 전체 Node 명령도 통과했다.
비정상 종료 뒤 남은 독점 잠금은 보수적인 복구 제한이다. 다른 앱 프로세스의
종료·저장소 안전을 확인하지 않고 지우거나 기존 회전 토큰을 다시 쓰지 않는다.

## 기존 hosted CI 실패와 후속 검증

이전 `acfa3474`의 fast `40056710597`은 첫 분할 질문을 보내기 전에 renderer의
데이터 복원이 끝나지 않아 `no_images`로 거절된 준비 경합이었다. hosted trace에서
질문 클릭은 20680ms, 거절 기록은 21248ms, 20장 summary 반환은 21380ms였다.
새 테스트는 실제 분할 버튼의 source/count 가드가 풀리고 전체 20장이 보일 때를
기다린다. 시간 제한·보호 단언을 약화하지 않았고 관련 실제 화면 검사에서 통과했다.
기존 head의 전체 회귀와 이 후속 head의 CI/병합은 별도로 확인해야 한다.

사용자 참여로 남는 것은 실제 로그인/플랜 동의·계정별 모델 접근/호출/갱신/철회,
처음 사용자 시간/클릭, 현장 정답 확인과 품질 수용이다. 로컬 자료의 실제 모델 진단은
[별도 기록](2026-10-24-real-image-foundation-diagnostic.md)에 있으며 합성 UI 검사와 구분한다.
