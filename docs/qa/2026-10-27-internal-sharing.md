# 10월 27일 내부 공유: 이 PC에서 브라우저로 실행

이 문서는 소스가 설치된 macOS PC의 localhost 시연용입니다. 계산과 저장은 실행한 PC에서 이루어집니다. [상세 실행 안내](../local-browser.md)를 함께 보세요.

## 실행 전

- 최종 병합 뒤 main 체크아웃을 사용합니다. 아래 Python 경로는 이 Mac에서 검증에 사용한 환경이며 작업트리 폴더와 함께 보존합니다. 다른 PC에서는 requirements를 설치한 자신의 `.venv/bin/python`을 지정하세요.
- 같은 물리 장치를 쓰는 다른 학습과 자원 사용이 겹치지 않는지 확인합니다. 서버 데이터 잠금이 GPU 독점 사용을 보장하지는 않습니다.
- 자체 서명 인증서의 주소·지문을 확인하고 브라우저의 최초 경고는 사용자가 처리합니다. OS 신뢰 저장소나 브라우저 전체 인증서 검사를 바꾸지 않습니다.

```bash
cd /Users/kai/Desktop/modu-vision-main
VISION_AI_PYTHON=/Users/kai/.local/share/modu-vision-worktrees/web-roundtrip-20261026/.superpowers/sdd/2026-10-26-web-roundtrip/venv/bin/python npm run web
```

준비 출력 뒤 **https://localhost:8443**을 엽니다. 포트가 사용 중이면 `npm run web -- --port 8444`처럼 다른 포트를 지정합니다.

## 시연 순서

1. 첫 실행이면 터미널에서 관리자 이름과 비밀번호를 만듭니다. 비밀번호는 채팅이나 공유 화면에 입력하지 않습니다.
2. 화면의 **더 보기 → 서버 관리 → 공동 작업 서버**에서 해당 localhost 주소와 로컬 계정으로 로그인합니다.
3. **프로젝트·계정 관리**에서 새 분류 프로젝트를 만들거나 기존 웹 프로젝트를 선택합니다.
4. **모두 보기 → 검증된 데이터 버전**에서 이미지 ZIP을 업로드·검증·채택하고 **이 ZIP으로 작업 시작**을 누릅니다. 채택과 작업 소스 선택은 별도 단계입니다.
5. 라벨을 저장하고 학습·검증·시험 분할을 저장합니다. 학습 설정 후 **로컬 준비 검사 → 선택 설정으로 학습 시작**을 사용합니다. 처음 공유에서는 합성·비민감 자료와 이미 준비된 모델 가중치를 사용하세요.
6. 완료된 작업을 **작업 센터 → 저장 작업 다시 열기 → 완료 후보 평가로 이동**에서 평가합니다. 저장 평가는 **평가 이력 · 제품/Lot별 오류 → 모델별 저장 평가**에서 엽니다.
7. 실행 터미널에서 Ctrl+C로 서버를 종료하고 같은 명령으로 다시 실행한 뒤, 로그인·프로젝트 선택 후 기존 작업·라벨·평가를 확인합니다.

실제 기능 확인에 쓴 학습 설정은 **ResNet18 · CPU · 1 epoch · 입력 64px · batch 2 ·
60초 예산**입니다. 합성 이미지 16장을 10/4/2로 나눈 시험이며 시험 정확도는 0%였습니다.
이 자료로는 모델 성능을 설명하지 말고, 저장·학습 실행·평가 오류 안내·재접속이 동작하는
흐름만 보여 주세요.

## 저장과 범위

기본 웹 계정·프로젝트는 `~/Library/Application Support/Modu Vision Web`에 보존합니다. Electron 데이터는 자동 이전하지 않습니다. 기존 학습·평가 결과를 보존하려면 같은 데이터 폴더로 재실행하세요.

검증 근거는 [통합 검증 기록](../verification/2026-10-26-local-web-integration.md)에 기록합니다. 합성 데이터에서 기능이 동작한 사실과 현장 모델 성능은 별개입니다. Windows 실행과 Linux/다른 브라우저 실사용, 네이티브 폴더 열기·ChatGPT 도우미·외부 공개 호스팅은 이 시연의 검증 범위가 아닙니다.

이번 공유용 localhost 작업과 PR #16의 공유 서버 보안 정비를 통합하되, 기존에 보류한 계정 잠금 정책·RTSP 주소 정책·익명 health 정보·renderer CSP 설계 전체가 해결됐다는 뜻은 아닙니다. LAN이나 인터넷으로 공개하지 않습니다.
