# 모두비전 다각형 점 편집

2단계 **라벨 달기**에서 다각형을 그린 뒤 **선택** 도구로 다각형이나
꼭짓점을 누릅니다. 점 편집 도구는 이미지 위를 가리지 않는 별도 줄에
표시됩니다. 처음 꼭짓점을 잡고 끄는 동안에는 새 도구 줄이 나타나지
않고, 마우스를 놓은 뒤 표시되어 드래그 좌표를 유지합니다.
임시 초안 보존 안내 등으로 화면 배치가 바뀌어도 드래그 시작 시점의
좌표와 배율을 기준으로 이동량을 계산합니다.

| 할 일 | 방법 |
| --- | --- |
| 점 선택 | 꼭짓점 클릭 또는 점 편집의 이전/다음 화살표 |
| 점 추가 | Shift를 누른 채 선택한 다각형의 변 클릭. `+`는 선택한 점 다음 변의 중간에 추가 |
| 점 이동 | 꼭짓점 드래그 또는 방향키. Shift+방향키는 10px 이동 |
| 점 삭제 | `−` 또는 Delete/Backspace. 최소 3점은 유지 |
| 도형 전체 선택 | 마우스 포인터 모양의 **도형 선택** 버튼 |
| 되돌리기 | 기존 실행 취소·다시 실행 버튼 또는 Ctrl/Cmd+Z, Ctrl+Y |
| 저장 | 기존 **저장** 버튼. 저장 후 이미지를 다시 열어 확인 가능 |

각 아이콘의 이름은 마우스를 올리면 보이고, Tab으로 이동해 Enter나
Space로 실행할 수 있습니다. 선택한 점은 더 크고 채워진 표시로 구분합니다.
도형 전체를 선택한 상태에서 Delete를 누르는 기존 캔버스 단축키는
도형을 삭제합니다. 점 도구 모음에 초점이 있고 점을 선택하지 않았다면
Delete/Backspace로 도형을 지우지 않습니다.

점 하나의 추가·삭제·키보드 이동은 기존 실행 취소 기록을 사용합니다.
이미지·프로젝트·라벨 세트·도구를 바꾸거나 실행 취소하면 점 선택을
해제합니다. 원본 픽셀 좌표, 라벨 ID·클래스·텍스트·방향·기계 초안 출처와
기존 저장 충돌·팀 편집·검수 정책을 유지합니다.

## 사용한 오픈소스

Label Studio의 순수 점 투영 함수 일부를 고정된 소스에서 가져와
TypeScript 시그니처로 연결했습니다. 선분 끝점과 길이 0 처리는 모두비전의
별도 함수가 담당합니다. Label Studio 전체 편집기·백엔드는 포함하지 않습니다.
