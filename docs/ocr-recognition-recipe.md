# OCR 인식 recipe

## 지원 범위

| 입력·작업 | 지원과 제한 |
|---|---|
| 기존 `crop` | 비어 있지 않은 단일 행 정답으로 CNN/GRU CTC를 학습하고 전체 crop을 인식한다. |
| 확장 `detect_recognize` | 단순 배경의 수평 문자 영역을 고전 영상 처리로 제안한 뒤 같은 CTC 모델로 읽는다. 위에서 아래로 행을 정렬하고 행 사이를 줄바꿈으로 연결한다. 학습 입력은 단일 행 crop이다. |
| 한글·숫자 | 학습 alphabet에 포함된 Unicode 문자만 인식 대상으로 삼는다. 선택 charset이 학습 alphabet을 포함하지 않으면 학습 전에 거절한다. |
| 미등록 문자 | val/test 정답에 train alphabet 밖의 문자가 있으면 정답 준비 단계에서 거절하고 학습 작업을 등록하지 않는다. |
| 빈 입력 | 빈 학습 정답은 허용하지 않는다. 영역 제안 모드의 빈 영상은 빈 문자열·영역 없음·점수 0을 반환하며 설정한 문자 규칙은 별도로 판정한다. |
| 세로 문자·학습 기반 장면 검출 | 지원하지 않는다. 수평 영역 제안으로 대체해 지원한다고 표시하지 않는다. |

문자 정규화, 전체 문자열 정규식, 최소·최대 문자 수와 정확한 허용 문자열 목록은 준비 검사·학습 요청·저장 checkpoint·추론에서 같은 recipe를 사용한다. 허용 문자열의 앞뒤 공백도 값의 일부다. 다중 행 규칙은 줄바꿈을 포함한 전체 결과에 적용한다. 문자 수는 backend의 Unicode 문자열 길이를 사용한다. 정규식은 256자 이내이며 최종 유효성은 backend가 검사한다.

## 학습 설정과 결과

화면에서 epoch, batch, 모델 입력 폭, 학습률, CPU/지원 장치 및 실행 시간 제한을 선택한다. 기존 기본값은 epoch 20, batch 8, 입력 높이 32/폭 128, 학습률 0.001이다. 짧은 문자열은 입력 폭과 최적화 설정을 확인해야 한다. 설정과 recipe는 모델 기록에 저장되며 후보를 다시 선택하면 batch·입력 폭·학습률과 문자 규칙을 복원한다. 시간 제한·queue·priority와 부모 후보는 공통 학습 경로를 사용한다.

시험 결과는 exact match, CER, WER를 구분한다. 없는 값·무한대·음수는 `측정되지 않음`으로 표시하며 오류율이 100%를 넘는 값도 그대로 표시한다. 기록된 낮은 오류율은 대표 데이터 품질 승인과 별도다.

## 원본 좌표와 후보 패키지

추론 화면의 SVG는 원본 크기와 원본 픽셀 영역을 사용한다. 플로우는 동일한 checkpoint의 recipe를 읽고 문자 규칙 실패를 NG 근거로 유지한다. 프레임과 ROI 좌표를 별도로 복원하며 다중 행 box·polygon·행 순서도 결과에 남긴다. 패키지 동등성 비교는 인식 문자열뿐 아니라 `ocr_regions`, `ocr_recipe`, `ocr_rule_result`도 검사한다.

개발용 후보 패키지는 전체 플로우와 정확한 모델을 복사해 독립 Python 프로세스로 실행할 수 있다. 승인된 배포 API의 품질·릴리스 승인을 대신하지 않는다. 실행 장치를 명시하고 API와 패키지의 장치·판정·영역·규칙을 함께 대조한다.

## 확인한 근거

Task102: 실제 Chrome과 macOS 개발 Electron에서 12개 손으로 그린 한글·숫자 단일 행 crop을 8/2/2로 준비하고 120 CPU epoch, batch 2, 입력 폭 32, 학습률 0.003, 60초 제한으로 학습했다. 저장된 두 시험 이미지 CER/WER는 0이며 원본 다중 행 `가1\n나2`를 실제 읽었다. 이 합성 입력과 설정은 기능 시험용이며 앞선 합성 입력 진단에서 선택했다. 대표성·독립 검토·untouched 현장 cohort 품질 근거가 아니다. 초기 20 epoch 후보의 CER/WER 100% 기록도 보존했다.

미등록 정답 거절, 원본 SVG 영역, 빈 영상의 규칙 실패, 정확한 모델/recipe 재열기, 모델 노드 연결, CPU 플로우 실행과 새 프로세스의 전체 후보 패키지 결과를 검증했다. 공개 근거 원장은 `docs/verification/2026-10-04-remaining-integration-evidence.md`에 있다. 원본·checkpoint·SQLite·평가·패키지 해시와 소유한 프로세스 종료는 별도 private receipt로 고정했다. Windows, 설치된 배포판·현장 장비·GPU·대표 장면 인식률과 인간 품질 승인은 이번 근거에 포함되지 않는다.
