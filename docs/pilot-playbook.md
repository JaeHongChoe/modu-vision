# First-use pilot and feedback

Status: pilot execution pending. The development agent is not a first-use pilot
participant and does not sign off user usability.

## Session

Invite a first-time user to complete the documented demo and then their own
approved data without step-by-step coaching: create/import, inspect data, label,
train, evaluate, edit/save a flow, inspect and review an error. Use a private copy
of data and agree beforehand whether screenshots or recordings may be retained.

Record participant/role, app/source/artifact version, platform, time per stage,
completed and blocked actions, unexpected OK or stale-version guidance,
recovery attempts, task abandonment and feedback. Distinguish observation from
suggested improvements. Remove real images, secrets and private paths from
public issues.

## Follow-up

Map each blocker to a tracked requirement and a reproducible regression. Critical
data-loss, unauthorized-access, incorrect-OK and stale-approval issues block the
public candidate until fixed and re-executed on the same path. Link the retained
pilot record and verified fixes into the release decision. Later pilots provide
feedback for the next version; they do not retroactively validate an earlier
release.
