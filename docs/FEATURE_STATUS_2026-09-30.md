# Modu Vision 기능 상태 · 2026-09-30

> **이전 구현 시점의 기록입니다.** 아래의 일부 미구현·미지원 표기는 후속 변경으로 달라졌습니다. 현재 기능과 검증 제한은 [최신 기능 구현 및 검증 범위](feature-completion.md)를 기준으로 확인하세요.

## 읽는 기준

`구현`은 아래에 명시한 입력·출력 경로의 코드와 검증 근거가 있다는 뜻이다. `부분`은 지원 범위가 제한된 상태다. `미구현`은 해당 기능의 실행 경로가 없는 상태이며, `미검증`은 코드가 있어도 해당 조건의 실행 근거가 없는 상태다. 기능 구현, 네이티브 앱 클릭, 실제 데이터 실행, 모델 품질, 현장 적용 승인은 서로 다른 판단이다.

세부 실행 기록은 [전체 데이터 기능 QA](QA_FUNCTIONAL_2026-09-29.md), [후속 기능 QA](QA_FEATURES_2026-09-30.md), [Phase 0~4 QA](QA_WORKFLOW_PHASES_0_4_2026-09-30.md)에 있다. 비공개 원본·이미지·고객 식별자·개인 경로·모델 파일·상세 영수증은 저장소에 포함하지 않는다.

- 최신 기능 변경에서 백엔드 **932 passed, 11 skipped, 95 warnings**, typecheck·build, 배치·이력 문맥 25개, 저장 버전 인계 7개, ROI 수치 4개, 레이블셋 목록 3개, 뷰포트·프로젝트 복구 회귀와 패키징 26개를 확인했다. [세부 기록](QA_WORKFLOW_PHASES_0_4_2026-09-30.md)의 실행 조건과 한계를 함께 읽어야 한다.
- 기존 원본 88장에는 독립 검증된 정상(OK) 정답 코호트가 없다. 1 epoch, NG 중심 자료, 같은 이미지의 결과 일치는 정확도·과검률·운영 승인 근거가 아니다.
- 대표 OK/NG 평가, 미구현 모델·자동화, 다중 사용자 협업, 승인 모델 서비스 적용·롤백, 실장비·연속 운전·장치별 호환성은 별도의 제품 수용 조건이다.
